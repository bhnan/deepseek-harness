# 每日文化素养词库规范 —— 内容结构与推送算法

日期：2026-08-19
状态：v1。与总览（`2026-08-19-teacher-calendar-overview.md`）同日定稿，是素养推送模块（F3）的**唯一内容标准**。
对应总览锚点：轨道 C（**C1** 词库结构 / **C2** 推送算法 / **C3** 词库可维护性）、数据实体 **D8**（素养词库数据，含推送状态）、**D9**（设置与元数据）。字段级定义以 `data-schema-spec` 为准；本文定义内容语义与推送算法。

## 1. 定位与目标

**核心业务价值**：为道德与法治教师每日备课提供持续的素养积累——每天打开日历时，看到一条经过校订、可直接用于备课或课堂的文化素养内容。

### 1.1 定位（一句话）

内置静态词库、离线可用；五类内容按既定算法轮换推送，每日一条、可手动换、同轮不重复，全程本地判定、无网络依赖。

### 1.2 设计原则（讨论共识）

1. **内容与算法分离**：词库（静态内容，`culture_entry.json`）与推送状态（运行状态，`push_state.json`）物理分离。词条增删只影响"可用池"，不破坏已推送记录。
2. **离线可用优先**：词库随插件内置打包，推送逻辑全部本地判定，断网可用（已确认决策）。
3. **按日期键控**：推送状态以"日期键"为准（当天首次打开取当日词条），不依赖"上次推送时间"的时间差判断。
4. **无重复是持久化承诺**：任何选条动作必须先写回推送状态、原子落盘，再向界面展示；界面只读状态，不自行选条。
5. **五类均衡轮换**：教育古语/古典诗词/国内外教育理念/教育学理论/教育心理学知识点五类交替覆盖，素养积累不偏科。
6. **面向备课可落地**：每条内容以"教师能直接引用、能落到课堂"为验收标准，杜绝空泛鸡汤。

**分类边界规则**（种子脚本与人工校订必须遵守，防类别归属漂移）：以词条"主要回答的问题"判定归属——

- 回答"教育应当是什么样、教育的价值取向" → 国内外教育理念；
- 回答"教师应当怎么教、教学与课程应当怎么组织" → 教育学理论；
- 回答"学生怎么学、心理怎么发展、动机情绪怎么运作" → 教育心理学知识点。
- 同一主题（如"最近发展区"）常被交叉引用，本文统一按上述规则归入**教育学理论**（教学组织视角），归属一旦确定不得随意迁移。

## 4. 推送算法（C2）

硬性标准：功能逻辑闭环、无冲突、无BUG，交互流畅、数据联动精准。本节定义算法与全部边界行为。

### 4.1 链路图

```text
culture_entry.json（静态词库，D8）
   │ 选择器过滤：已推送(pushed_ids) / 不喜欢(disliked_ids) / 已删除
   ▼
可用池（当前轮次可推词条）
   │ 当日选条（类别轮转 + 类内随机不重复，§4.5）
   ▼
push_state.json（D8 推送状态：by_date / pushed_ids / round）
   │ 前端读取（当天首次打开视图时）
   ▼
素养卡片：每日自动更新 + 手动刷新
```

### 4.2 每日自动更新：按日期键控

- **触发时机**：当天首次打开素养卡片视图时（不设定时器、不依赖后台任务）。
- **判定方式**：以日期字符串为键（如 `2026-09-01`），查推送状态 `by_date`：
  - **命中** → 直接展示该日期键对应的词条（幂等：同一天多次打开、多窗口打开结果一致）；
  - **未命中** → 由选择器取一条未推送词条，写入 `by_date[当日]` 并原子落盘，再展示。
- **为什么不记"上次推送时间"**：时间差方案依赖"距上次 ≥ 24 小时"判断，跨零点、时区变化、设备时钟回拨都会出错；按日期键控只看"今天的键有没有记录"，与时钟差值无关，天然幂等、无状态竞态。
- **数据联动**：当日记录同时驱动卡片上的"第 N 条 / 轮次"计数；`by_date` 历史在学期目录内保留，供学期视图回溯（P1）。

### 4.3 手动刷新换内容

- **行为**：点"换一条"→ 选择器从可用池取**下一条未推送**词条 → 覆盖 `by_date[当日]` → **被换下的原词条一并计入 `pushed_ids`**（保证"无重复推送"语义严格成立）→ 原子落盘。
- **幂等与防抖**：刷新结果落盘后，当日再打开显示刷新后的词条；连续点击按轮换流顺序依次取条，直到可用池耗尽 → 提示"今日词库已轮换完毕"。
- **与每日自动更新的关系**：手动刷新只改当日键的值，不改变次日行为——次日进入新日期键，重新自动取条。

### 4.4 无重复推送的持久化保证

- 推送状态持久化三个核心部分（字段名以 schema 文档为准）：**`by_date`**（日期 → 词条 id）、**`pushed_ids`**（全局已推送 id 集合）、**`round`**（当前轮次）。
- **选条约束**：只允许从「可用池 − `pushed_ids`」中取；取出即写入 `pushed_ids`；写盘走原子写入（X3：临时文件 + rename）。选中即永不重复（同一轮内）。
- **展示来源唯一**：卡片只读 `by_date[当日]`，不自行选条——杜绝"界面显示的"与"库里记的"不一致。
- **持久化位置**：随学期目录隔离存储（与 G6 学期数据隔离、D9 设置一致），学期切换见 §4.7。

### 4.5 轮换顺序策略（随机不重复 vs 顺序循环）

| 候选 | 机制 | 优点 | 缺点 |
|------|------|------|------|
| A. 随机不重复 | 可用池洗牌后逐条取（Fisher-Yates），不重复直至耗尽 | 顺序不可预测、体验新鲜 | 纯随机可能出现同类连续推送 |
| B. 顺序循环 | 按 id/入库顺序固定遍历 | 实现最简单、确定性最强 | 同类可能扎堆、顺序可被预判 |

**建议（默认）**：**类别轮转打底 + 类内随机不重复**的混合策略——

- **类别维度顺序轮转**：五个推送日对应五类循环（第 1 天教育古语、第 2 天古典诗词、第 3 天国内外教育理念、第 4 天教育学理论、第 5 天教育心理学知识点，第 6 天回到教育古语），保证任意连续 5 个推送日五类各出现一次，素养覆盖均衡；
- **类内维度随机不重复**：同一类内部按洗牌顺序取，同类内部不重复、顺序不可预测。

**理由**：教师对"一周内能看到各类内容"的体验优于纯随机；顺序循环确定性最强但可预判、易"背答案"。混合策略兼具均衡与新鲜。实现上：选择器 = 类别游标（取当前"类内已推送数最少"的类别，等价于五类循环）+ 类内未推送洗牌列表；状态全部可落盘，重启不丢。**顺序循环（B）保留为设置中的可配置备选**（D9）。

### 4.6 词库耗尽行为（"第二轮"）

- **判定**：`pushed_ids` 覆盖当前可用池全部词条（可用池 = 全部词条 − 已删除 − 标记不喜欢）。
- **行为**：重置 `pushed_ids` 为空 → 重新洗牌 → `round + 1` → 卡片标注"第二轮"（如徽标「第二轮 · 第 3/192 条」）。
- **语义**：同一轮内严格不重复；跨轮允许重复（否则第二轮无内容可推）。
- **空库/全排除降级**：可用池为空时显示占位提示"词库暂无可用词条，请前往词库管理"，不崩溃（X1 zod 降级思路）。

### 4.7 跨学期推送状态——建议

**建议：推送状态不跨学期保留**——每学期初始化 `round = 1`、`pushed_ids` 清空；`by_date` 随学期目录隔离存储，历史学期目录保留可回溯查看（与 G6 学期数据隔离、D9 设置一致）。

**理由**：一学期推不完 150+ 条（约 139 自然日 / 约 100 教学日，见 §5.2）；若跨学期累积 `pushed_ids`，第二学期可用池骤减、很快进入"第二轮"，教师会在同一学期内看到大量重复，违背"无重复推送"在本学期的体验价值。素养积累是持续需求，词条每学期重新出现是预期行为。

**可选（P1）**：设置中提供"重复周期"（一学期 / 一学年），供教师按需调整。

### 4.8 边界与降级清单（逻辑闭环）

| 场景 | 行为 |
|------|------|
| 同一天多次打开 | 同一词条（日期键控幂等） |
| 当日手动刷新后再打开 | 刷新后的词条（当日键已更新） |
| 跨零点连续打开 | 新日期键 → 自动取新词条 |
| 设备时钟回拨 / 时区变化 | 不受影响（不依赖时间差） |
| 多窗口 / 多标签并发 | 原子写入 + 日期键控幂等，不重复选条 |
| 当日词条被用户删除 / 标记不喜欢 | 卡片降级提示"可手动刷新换一条"，不崩溃 |
| 可用池耗尽 | 重置 `pushed_ids`、轮次 +1、标注"第二轮" |
| 可用池为空（全删除/全不喜欢） | 占位提示，不崩溃 |
| 词库文件损坏 | 读入校验失败 → 降级占位，提示重建（X4 完整性可发现） |

### 5.2 覆盖计算

- 秋季学期 2026-09-01 ~ 2027-01-17 ≈ **139 自然日**；按"每日一条（含周末）"口径，建议量 192 条覆盖全学期且余 **53 条**；最低标准 150+ 亦可覆盖。
- 按"仅教学日"口径（约 **100 个教学日**，对应"一学期 20 周 100 个教学日不重复"的需求），余量约 **92 条**，支持整个学期每日手动刷新仍有富余。
- 结论：**150+（建议 192）满足两种口径的整学期不重复**，并为手动刷新留出余量。

|------|------|

## 6. 内容质量规范

### 6.1 文言翻译准确度要求

1. 以通行权威版本与译注为准（中华书局、人民文学出版社等通行本），白话翻译做到"字字有据、句意通达"：直译保真为主、意译达意为辅。
2. 禁止采用网络流传的戏说、恶搞译文；译文须经人工复核后方可入库。
3. 原文照权威版本抄录，版本信息记入"来源出处"字段；同一词条不同版本有异文时，选择通行版本并可在出处中注明。

### 6.2 通俗释义写作规范

1. **面向教师**：以道法教师为读者，用教师熟悉的语言，禁止学术黑话堆砌。
2. **结合课堂场景**：每条释义结构 = 核心含义一句话 + "课堂/备课怎么用"落地提示一句；篇幅 50–120 字。
3. **可落地验收**：释义必须让教师"能直接引用、知道在哪个场景用"；禁止空泛鸡汤、禁止只讲道理不给用法。
4. 示例见 §2 各类别词条（如皮格马利翁效应的释义含"开学初记闪光点"的具体做法）。

### 6.3 禁入内容

1. **不涉政治敏感**：不收录涉政、涉领导人、涉民族宗教纠纷、涉敏感历史事件的内容；国内外教育理念只取公认教育学术范畴的主张。
2. **不涉宗教**：不收录宗教经典、教义、宗教仪式相关内容；古典诗词仅从文学与育人价值角度收录。
3. **版本权威性**：原文以权威通行本为准，出处可考才收录；**托名伪作、无法核实出处的"名言"一律不收录**（如网络上无出处的"孔子说""苏格拉底说"伪名言）。
4. **底线**：与未成年人保护、师德师风要求相冲突的内容不收录；争议性教育主张需注明争议或弃用。

## 7. 可维护性（C3，P1）

### 7.1 能力清单

| 能力 | 说明 |
|------|------|
| 新增词条 | 表单录入 + 自定义词条入库流程（§7.2） |
| 编辑词条 | 修改字段后重新校验落盘；已推送历史按 id 引用同步更新展示 |
| 删除词条 | 从可用池移除，不再参与推送；历史引用展示时降级为"词条已删除" |
| 标记不喜欢 | 写入推送状态（不喜欢 id 集合），排除出自动推送与手动刷新；可取消恢复 |
| 自定义词条入库 | 教师自建词条进入可用池（§7.2） |
| 批量导入（可选） | 复用总览 I1 的 CSV/Excel 导入导出能力 |

### 7.2 自定义词条入库流程

```text
表单填写（类别/原文/白话翻译[文言类]/通俗释义/标签/难度/来源）
   │ 字段校验（必填规则 §3.3、长度、类别枚举、标签去重）—— 失败返回表单定位错误
   ▼
预览确认（按卡片形态预览）
   │ 确认
   ▼
落盘（生成 id、created_at=当天、原子写入 culture_entry.json）
   ▼
进入可用池（立即生效：当日已推送则次日可选到，手动刷新亦可选到）
```

### 7.3 删除与"不喜欢"对推送的影响

1. **删除**：从可用池排除，不参与后续推送与轮次耗尽判定；已推送历史（`by_date` 引用）保留，展示时降级为"词条已删除"。
2. **标记不喜欢**：写入不喜欢集合，自动推送与手动刷新均不再出现；可随时取消恢复。
3. **当日冲突**：若当日词条被删除/标记不喜欢，当日键控记录不动，卡片降级提示"可手动刷新换一条"——管理操作与当日推送互不覆盖，保证"数据联动精准、无冲突"。
4. 全部管理操作实时生效、原子落盘，与推送算法无竞态（选条只读持久化状态，管理操作只改词库与排除集合）。
