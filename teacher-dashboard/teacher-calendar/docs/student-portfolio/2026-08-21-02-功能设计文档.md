## 1. 应用总览

独立应用「学生成长档案工作台」（默认标题：梁老师的学生成长档案），
前端 Vite（5174）+ 后端 Express API（8797）+ SQLite 单文件库（data/student-portfolio.db）。
独立 DSH 侧栏按钮（📁 成长档案）嵌入，热插拔。

```
┌──────────────────────────── 全局框架（所有页面常驻） ────────────────────────────┐
│ 顶部栏：📁 <可编辑标题：梁老师的学生成长档案>   [全部|小学|初中]  [主题▾] [备份][撤销][恢复][导出] │
│ 板块导航：〔班主任主班〕〔道法代课〕〔全局设置〕                                        │
│ 知识卡片（顶部常驻，形态同教学日历「名言古语」）：[标签▾：班主任干货] 今日条目摘要… [换一条][展开] │
└──────────────────────────────────────────────────────────────────────────────┘
```

## 2. 全局框架功能（对应 FR-1.1 / FR-1.6 / FR-1.7 / FR-4.1）

### 2.1 顶部栏
| 元素 | 行为 |
|---|---|
| 标题 | 默认「梁老师的学生成长档案」；点击 ✏️ 内联编辑（教师姓名 + 标题同字段编辑，如「王老师的学生成长档案」），localStorage + 设置库双持久化 |
| 学段筛选 | 「全部 / 小学 / 初中」三键；选中后全局生效（班级列表、学生列表、看板、统计均按学段过滤）；偏好持久化 |
| 主题切换 | 简约风 / 小清新风 / 艺术风（≥3 套，与教学日历主题机制同构），一键全局切换，持久化 |
| 备份 | 一键备份 → 打包（student-portfolio.db + uploads/ + 密钥除外）下载 |
| 撤销 / 恢复 | 全局操作栈，覆盖所有写操作 |
| 导出 | 当前学段/板块数据的 CSV/JSON 打包导出（隐私字段默认脱敏，可选明文——明文导出需二次确认） |
| 知识卡片 | 顶部栏下方常驻轻量卡片（FR-5.2/5.3，形态同教学日历「名言古语」卡片）：默认显示当日推送 1 条；4 类标签切换（班主任干货/道法干货/心理实操/金句）；「换一条」手动刷新（当日去重）；点击展开全文；卡片内收藏、记笔记、一键转话术文案；「更多」→ 轻量检索页 |

### 2.2 板块导航
| 板块 | 权限范围 |
|---|---|
| 班主任主班 | 仅列出 role=homeroom 班级（1 个初中主班）；全功能档案（FR-2 全部模块） |
| 道法代课 | 列出 role=subject 班级 + 主班（主班以「★主班（对比参与）」标识，仅参与道法统计不开放精简档案编辑）；精简功能（FR-3） |
| 全局设置 | 标题/姓名、主题、日历联动配置（API 地址、兜底学期）、知识库（轻量检索/复盘导出入口）、数据管理（备份/恢复/重置） |

> 知识库**不设独立板块**：内容入口 = 顶部知识卡片（FR-5.2）+ 卡片「更多」进入的轻量检索页 + 全局设置内的复盘导出（FR-5.6）。

## 3. 班主任主班板块（FR-2）

### 3.1 班级列表页
- 卡片/表格列出主班班级：班级名、年级、学段、学生数、最近考试、作业完成率摘要。
- 支持新建/改名/删除（删除二次确认，级联删除需输入班级名确认）。

### 3.2 班级详情页（Tabs 结构，一人一档入口）

```
班级详情页 Tabs：〔学生名单〕〔成绩分析〕〔作业台账〕〔德育心理〕〔特长荣誉〕〔成长素材〕〔智能评语〕〔家校话术〕
```

#### Tab1 学生名单（FR-2.1）
| 功能 | 说明 |
|---|---|
| 学生列表 | 表格：姓名、学号、性别、出生年月、住校、压力等级、特殊备注图标（🔒 点击查看加密字段，需输入查看密码？——简化：本机直接查看，导出才脱敏） |
| 新增/编辑学生 | 弹窗表单：全字段（FR-2.1.1~2.1.3）；敏感字段输入框右侧显示🔒标识（加密存储） |
| 批量导入 | CSV 模板下载 + 上传解析；逐行校验并报告错误行（班级名映射、必填项、格式校验） |
| 筛选导出 | 按姓名/学号/性别/住校/压力等级筛选；导出 CSV（默认脱敏：身份证/电话/住址打码 `138****1234`） |
| 学生详情 | 点击姓名进入「学生个人档案页」：成长时间线（见 3.9） |

#### Tab2 成绩分析（FR-2.2）
| 功能 | 说明 |
|---|---|
| 考试管理 | 新增考试（名称、类型、日期）；表格批量录入各科分数/排名（Excel 粘贴兼容：`学号,语文,数学,...,总分`）；编辑/删除考试（级联删除成绩） |
| 班级学情面板 | 本次考试：平均分、优秀率(≥85)、及格率(≥60)、分数段分布条形图、较上次考试总分进退步学生数 |
| 个人分析入口 | 学生列表内嵌「进/退/稳」状态徽标；点击查看个人波动曲线（折线图，按时间序） |

#### Tab3 作业台账（FR-2.6）
| 功能 | 说明 |
|---|---|
| 布置作业 | 新增作业：日期、学科、内容、要求、截止时间（可一键生成家长群通知话术，跳转话术库） |
| 作业记录 | 按作业批量录入每生完成状态（优质/正常/补交/缺交/敷衍/抄袭）+ 问题备注 + 整改要求；支持按状态筛选、补录 |
| 统计面板 | 周/月/学期维度：班级完成率、缺交/敷衍/优秀次数 Top 榜、问题学生清单、高频问题标签云；个人作业态度趋势图 |
| 学情联动 | 某学生「作业问题次数」与「最近两次考试退步幅度」对照卡（仅展示关联，不自动定性） |

#### Tab4 德育心理（FR-2.3）
| 功能 | 说明 |
|---|---|
| 记录新增 | 弹窗：学生、日期、类别（情绪心理/家庭动态/人际关系/思想品德/奖惩/违纪/志愿服务/其他）、学段（自动按学生学段）、内容、跟进措施、跟进结果 |
| 列表 | 按学生/类别/日期筛选；按学期自动汇总视图（每生每类记录数 + 最近跟进结果） |
| 德育综合素质报告 | 学期按钮「生成报告」：按该生本学期德育记录自动汇总成文（分类汇总 + 亮点/需关注项 + 评语素材引用），可编辑导出 |

#### Tab5 特长荣誉（FR-2.4）
| 功能 | 说明 |
|---|---|
| 个人特长 | 学生维度：类别（艺术/体育/科创/书法/口才/乐器/其他）、名称、能力等级（入门/熟练/特长级）、发展潜力备注 |
| 个人荣誉 | 学生维度：奖项名称、级别（校级/区级/市级/省级）、赛事、日期；可关联成长素材中的证书（material_id） |
| 班级荣誉 | 班级维度：集体奖项、文明班级、活动荣誉，统一归档 |
| 列表视图 | 按学生/级别/学段筛选；学段差异提示（小学文体兴趣类 / 初中学科科创类） |

#### Tab6 成长素材（FR-1.3）
| 功能 | 说明 |
|---|---|
| 上传 | 多文件上传（图片/视频/PDF/文档，单文件 ≤ 50MB）；选择归属（班级/学生）、分类（课堂表现/运动会/活动实践/日常风采/获奖证书/班级荣誉/活动合影/其他）、事件日期、备注；**学期自动归档**（按事件日期推导：09-01~01-31 秋季 / 02-01~07-31 春季，缺省按上传日期） |
| 浏览 | 按班级/学生/分类/学期筛选；网格预览（图片缩略图、其他类型图标）；点击查看大图/播放/预览 |
| 导出 | 单素材下载；批量打包下载（zip）；学期相册导出（按学期一键打包该班该学期全部素材） |
| 成长轨迹 | 按时间线视图展示学生素材（可视化成长轨迹） |

#### Tab7 智能评语（FR-1.4 / FR-2.5）
| 功能 | 说明 |
|---|---|
| 生成 | 选择学生 + 评语类型（谈心话术 / 家校沟通评语 / 阶段性综合素质评语）+ 学期/时间范围 → 本地规则引擎自动生成（数据来源：成绩进退步、作业状态、德育心理、特长荣誉） |
| 编辑保存 | 生成后可修改；保存后进入「已保存评语」列表，可复用（复制到其他学生再改）、导出 |
| 模板管理 | 内置评语模板 + 自定义模板收藏 |
| 导出 | 全班评语批量导出（CSV/Word 兼容文本）：`姓名,评语类型,内容` |

#### Tab8 家校话术（FR-2.7）
| 功能 | 说明 |
|---|---|
| 话术库列表 | 分类：作业布置/家校监督/安全专项/物资携带/自定义；学段标签（小学/初中）；语气（严谨/温和）；收藏 |
| 一键生成 | 模板 + 占位符替换：`{班级} {日期} {作业} {学科} {截止} {学生} {家长}` 等；生成后可在文本框直接修改、复制 |
| 模板管理 | 新增自定义模板、收藏、复用；双学段分离（小学话术侧重习惯养成/温和鼓励；初中侧重自律/青春期/升学） |

## 4. 道法代课板块（FR-3）

### 4.1 班级列表页（精简）
- 列出 role=subject 班级 + ★主班（对比参与）。
- 每班摘要：道法平均分（最近一次）、优秀率、及格率、分层人数（培优/中等/基础）。

### 4.2 班级道法学情页
| 功能 | 说明 |
|---|---|
| 成绩录入 | 批量导入道法成绩（学号,分数[,班级排名]）；小学附加课堂素养评分（0-100） |
| 学情面板 | 本班：平均分/优秀率/及格率/分数段/较上次进退步 |
| 多班对比 | 跨班对比表：各班最近一次**同类型**考试（type+最近日期对齐）的平均分/优秀率/及格率/分数段横向对比 + 柱状图；支持小学/初中分组对比 |
| 个人追踪 | 学生列表内嵌进退步徽标；点击查看个人道法趋势线 |
| 题型短板 | 录入成绩时可附带题型得分（选择/简答/材料分析/论述）；自动统计各题型失分率，班级共性短板 Top3 + 学生个性薄弱点清单；小学侧重基础识记与课堂素养，初中侧重主观题逻辑与考点 |

### 4.3 智能分层页（FR-3.3）
| 功能 | 说明 |
|---|---|
| 自动分层 | 一键执行：权重规则（成绩 60% + 题型短板 25% + 课堂表现/作业 15%）→ 培优层 / 中等提升层 / 基础补差层；小学以兴趣习惯为主、初中以应试能力为主（权重随学段调整）；结果预览（可撤销） |
| 人工微调 | 拖动/下拉调整学生层级，标注 source=manual |
| 分层配套 | 每层自动生成：辅导重点、分层作业方案、课堂提问与训练建议（模板 + 班级数据填充）；可编辑导出 |

### 4.4 道法作业台账（FR-3.4.1）
- 与主班作业台账同构的精简版：仅道法学科；统计班级完成率、缺交/敷衍榜、错题整改情况。

### 4.5 道法素材与学科评语（FR-3.4.2 / FR-3.4.3）
- 素材：课堂精彩展示、学科活动、竞赛荣誉、班级学科表彰（归档同 FR-1.3 机制，分类含 df_*）。
- 学科评语：一键生成「道法学情反馈 / 家校沟通话术 / 学科学习评价」，聚焦学科态度、成绩进退步、短板提升。

## 5. 顶部知识卡片 + 轻量知识库（FR-5，辅助模块）

> 定位（定稿调整）：知识库**不作为独立板块**；呈现形态与教学日历「名言古语」卡片一致——单条常驻卡片，不占主界面。

### 5.1 顶部知识卡片（全局常驻）
```
[📖 知识卡片]  [标签▾：班主任干货 | 道法干货 | 心理实操 | 金句]   今日条目标题摘要…  [换一条] [展开 ▾]
```
- 位置：板块导航下方常驻，所有页面可见（同教学日历 TopBar 名言古语卡片）。
- 默认显示当日推送 1 条（FR-5.3）；4 类标签点击切换（每类当日 1 条，互不干扰）。
- 「换一条」：手动刷新该类当日条目（当日去重，记录替换）。
- 「展开」：下拉展开全文 + 来源/分类标签 + 操作按钮 [收藏] [记笔记] [一键转话术]（①班主任干货 ②道法干货 ③心理实操 → 家长群通知/谈心话术文案；④金句 → 班级寄语），复制即用（FR-5.5）。
- 「更多…」：跳转轻量检索页（5.2）。
- 学期节点适配：按当前日期自动匹配节点主题池（开学立规 / 日常学风 / 期中期末复盘 / 考前疏导 / 假期安全 / 青春期专项），推送优先从对应主题池选取（FR-5.4）。

### 5.2 轻量检索页（入口：卡片「更多」）
- 单页布局（非板块）：关键词检索框 + 四大库筛选（教育名著精华 / 学段心理专项 / 名师实操经验 / 教育家金句）+ 学段筛选 + 收藏 Tab；内容按七大分类目录组织（班级常规管理 / 问题学生专项疏导 / 跨学段育人指导 / 家校沟通体系 / 道法学科专属教学 / 学生心理健康教育 / 教师自我成长）。
- 条目操作：收藏、笔记、复制（FR-5.6 检索部分）。

### 5.3 复盘导出（入口：全局设置页 → 知识库）
- 按周/月/学期生成：该周期推送精华列表（自动聚合推送日志）+ 教师学习台账（收藏/笔记汇总）+ 德育工作小结（自动成文模板）；一键导出（Markdown 兼容文本），用于教研总结、师德考核、职称材料（FR-5.6）。

## 6. 全局设置页

| 分组 | 项 |
|---|---|
| 基本 | 工作台标题、教师姓名（默认「梁老师」） |

| 关于 | 版本、数据目录路径、文档链接 |

## 7. 页面路由清单（前端）

| 路由 | 页面 | 板块 |
|---|---|---|

## 9. 与教学日历的唯一联动（FR-7，功能视角）

- 入口：学生档案页 / 学生列表「＋ 沟通安排」按钮；道法班学生同样可建（仅谈心/私聊类）。
- 表单：类型（谈心/家访/家长约谈/私聊安排）、学生、日期、时间、地点、内容备注。
- 保存行为：写入本地 communications 表（synced=pending）→ 立即尝试同步教学日历（POST events，type=activity，title=`💬 {类型} · {学生}（{班级}）`，notes 前缀 `【成长档案】`，date/time 透传）→ 成功置 synced=1 并记录 calendar_event_id；失败置 synced=0 并在列表显示「⚠ 未同步 [重试]」。
- 学期匹配：按 date 在教学日历学期列表（bootstrap.semesters）中匹配；无命中 → 兜底学期；兜底也无效 → 同步失败并可重试。
- 撤销沟通安排时：同时删除已同步的日历事件（DELETE /api/calendar/:sid/events/:eid，使用记录的 calendar_event_id）。
