# 用户故事与组装方式 —— 教师教学工作日历

日期：2026-08-19
状态：v1，本稿。配套画面示意稿：`templates/teacher-calendar-mockup.html`（实现阶段 M0 前补齐，当前目录尚未提交）。
用途：作为整体愿景与验收场景——各里程碑完成时对照本文档核对"用户故事是否走得通"。
功能编号以总览（`2026-08-19-teacher-calendar-overview.md`）为准：轨道 F（视图与功能）F1–F14、轨道 G（全局）G1–G6、轨道 D（数据）D1–D9、轨道 R（规则）R1–R7、轨道 C（内容库）C1–C3、轨道 I（导入导出）I1、轨道 P（插件）P1–P4。
术语统一口径：**授课班级 / 授课内容**（单科双模块）、**固定排课 / 临时调课**（F7/R4）、**学期总周数**（R1，全站唯一周数口径，开学前不计数）。

## 1. 组装图：它如何长到 DSH 身上

```text
~/.dsh/profiles/web/                       ← 用户的 DSH 实例（已存在）
├── package.json          依赖中加入 @bhn/teacher-calendar
└── cordis.patch.yml      insert: 插件条目（与 deepwiki/context7 MCP 同一套机制）

@bhn/teacher-calendar（插件包，位于教学日历仓库 plugins/ 目录）
├── host 半边     注册 /api/calendar/* 路由 → 读写 data/（JSON 持久化，P2；禁 localStorage）
└── client 半边   React slot 注册 → 侧栏「教学日历」入口 + 顶部板块 + 三视图 + 主题渲染

data/（数据目录：多学期隔离存储，G6）
├── semesters.json            学期注册表（D1/R2）
├── manifest.json             X4 完整性清单（sha256 + 行数）
├── _global/                  全局资产（跨学期共享）
│   ├── classes.json          班级库（小学+初中双库、自定义名称+配色，D2/F5）
│   ├── theme.json            五套主题定义（D7/F14）
│   ├── culture_library.json  素养词库（五类，C1）
│   ├── teaching_presets.json 授课内容预设词库（D4）
│   ├── holidays.json         法定节假日表（G5）
│   └── settings.json         当前学期/视图偏好/主题/撤销栈（D9）
├── 2026-fall-s1/             ← 2026 秋季第一学期（2026.09.01—2027.01.17）
│   ├── fixed_courses.json    固定排课（授课班级每周固定复用，D3）
│   ├── temporary_changes.json 临时调课（仅当周生效，R4）
│   ├── teaching_content.json 授课内容（每周独立更新，D4）
│   ├── events.json           课程/活动/个人事务 五要素详情，D5
│   ├── birthdays.json        师生生日（归入左侧标准事件体系，D6）
│   └── push_state.json       推送状态（每日一条/无重复，按学期一轮，C2）
└── 2026-spring-s2/            ← 历史学期（2026 春季第二学期，仅供回溯查看，G6）
```

要点：插件是"长进"DSH（注册 slot），不是"替换"DSH；DSH 原生的会话、工具、文件系统全部保留，教学日历与会话同屏。学期数据只走 host 路由落本地 JSON（P2），多学期隔离存储（G6）——即使换机/重装，`data/` 目录仍在，历史学期永久可回溯。

## 2. 用户故事（2026 秋季第一学期 · 2026.09.01 开学 — 2027.01.17 放假）

人物：梁老师，道德与法治教师，跨年级授课——初一 5 个班（初一(1)–(5)班）+ 小学四年级 3 个班（四(1)–(3)班）。
环境：办公室 Windows 台式机 + 家用 Mac，Chrome 打开 `http://127.0.0.1:3080`，进入的是熟悉的 DSH，左侧侧栏多了一个「教学日历」入口（P1 slot 注册）。

### 2.1 开学前（8 月 24–28 日）—— 播种

**8.24（周一）新建学期。** 首次点击「教学日历」，顶部学期信息区（F1）为空态引导「请选择或新建学期」。梁老师点「学期管理 → 新建」，名称下拉选**「2026年秋季第一学期」**（标准化名称，年份+秋季+第X学期），起止日期**自动带出 2026.09.01 — 2027.01.17**（D1/R2 名称-日期强制联动绑定表，弹窗内可改），保存。顶部立即呈现：学期进度条 0%，**左右两端标注「9.1 开学」「1.17 放假」**（F1/R6）；周数徽标显示「未开学」——开学前不计数（R1）。同一时刻，学期下拉里还预置了只读历史条目「2026 春季第二学期」（上学期，日期为其存档值，不在 R2 绑定表内，供日后回溯，G6）。

**8.25（周二）建班级库（F5）。** 打开班级管理：先导入学校下发的班级名单 CSV（I1）自动生成条目，再逐个微调。小学库（四年级）：四(1)班=浅绿、四(2)班=浅蓝、四(3)班=浅黄；初中库（初一）：初一(1)–(5)班=固定五色。每个班**自定义名称 + 专属固定配色**（D2）；此后任何下拉选班都**自动匹配该班颜色**，禁手输、禁临时取色（F5）。

**8.26（周三）排固定课表（F4/F6）。** 切到周视图，逐时段点空格子 → 新建 → 类型「课程」→ **授课班级**下拉选「初一(1)班」（格子自动带上该班配色）→ **授课内容留空**（开学逐周再填）。9.1（周二）第 1 节初一(1)班、9.2（周三）第 3 节四(1)班……一周排完，后续每周**授课班级自动复用**（D3 固定排课长期复用）；**授课内容每周独立更新**（D4，与班级排课解耦）——这就是"单科双模块"。

**8.27（周四）导入师生生日（F13/I1）。** 「批量导入 → 师生生日」，选 `birthdays-2026.csv`（姓名/出生日期两列）→ 预览 → 确认。导入后生日**归入左侧标准事件体系**（F10/D6），不在课时区重复展示（R7）。顺手把上学期的生日名单也导入历史学期「2026 春季第二学期」留档。切回周视图第 1 周：9.1 星期栏日期格内小字出现「李想 · 生日快乐」。

**8.28（周五）素养推送 + 主题试切。** 顶部推送卡显示今日条目：「教育古语 · 教学相长」——原文下是**白话翻译**与**通俗释义**（F3/C1）。点「换一条」手动刷新（C2），连点两次不重复。再点顶部主题入口（F14）依次试「小清新 / 国风 / 极简艺术 / 轻量科技 / 治愈暖风」，最终留在「小清新」——**仅变视觉，数据原样**。

### 2.2 开学第一周（9.1–9.6）—— 开学

**9.1（周二）早 7:50。** 打开日历：顶部学期信息区显示「2026 秋季第一学期」，进度条约 1%，两端仍标「9.1 开学 / 1.17 放假」；周数徽标变为**「第 1 周」**（R1 开学起从第一周顺次累加）。**今日待办（F2）已自动汇总**：4 节固定课程 + 2 条个人事务，其中「提交教研组学期计划」昨晚已勾完成，显示**对勾 + 删除线**，仍留在列表里（不自动删除、永久留存）。周视图上 9.1 当日格子**三层级底色高亮**（F14：工作日浅底 / 周末与节假日深一档 / 当日高亮描边）；顶部星期栏 9.1 格内小字「李想 · 生日快乐」（R7）。素养推送今日条目已于自然日 0 点自动轮换（C2）。

**9.2（周三）课后。** 今日待办里点「批改四(1)班作业」→ 对勾变绿、文字加删除线；再点一下取消完成态——状态可来回切换（F2）。

### 2.3 每周日常（9.7 起，每周一早上）—— 备课

**9.7（周一）备本周课。** 周视图顶部固定「本学期第 2 周」，用「上一周 / 下一周」箭头切换（F4，无加减按钮）。本周 9 个班次的**授课班级已自动复用固定排课**（D3）——她只需填**授课内容**（D4）：点 9.8（周二）第 1 节「初一(1)班」→ 内容区下拉选预设词库「第一课 · 中学时代」，或手动输入；保存后班级排课纹丝不动，内容独立更新（F6 预设词库 + 手动自定义双模式）。

### 2.4 学期中（10 月）—— 应变

**9.30（周三，第 5 周）国庆调休。** 学校通知：10.1–10.7 放假、10.10（周六）调休补课。切到第 6 周（10.5–10.11）：10.6（周二）的「初一(5)班」课时格子显示**「国庆节」+ 节假日底色**（G5 全域标注，无论是否放假均文字提醒）。右键该课 → 「临时调课」→ 目标时段 10.10（周六）第 2 节 → 保存（F7/R4：**仅当周生效**）。再切到第 7 周：10.13（周二）第 2 节仍是固定课表原样——临时调课不污染固定排课（R4）。

**10.12（周一，第 7 周）课程智能顺延（F7/R3，单班内容序列）。** 初一(1)班的授课内容序列本是 [第一课·一.1 → 一.2 → 一.3 → 一.4]（分布在该班不同上课时刻）。因临时变动，10.13（周二）第 2 节内容改为「复习」。保存后系统自动顺延该班内容序列：一.2 顺延到第 3 节、一.3 顺延到第 4 节、一.4 顺延到该班下一节课，并提示「已自动顺延，请确认」——**只动了初一(1)班的内容顺序，其他班级的课、所有课时槽位一概不动，无课程冲突**（R3）。

**10.15（周四）。** 今日待办「整理月考成绩」标记完成（F2）——它和所有历史任务一起永久留存，不自动消失。

**10.16（周五）手动刷新素养。** 推送卡连点 3 次「换一条」：古典诗词「随风潜入夜，润物细无声」→ 教育理念「陶行知生活教育」→ 教育心理学「最近发展区」，**无一重复**（C2 全库去重，推送状态落盘 D8）。

**10.20（周二）月视图看全景。** 切月视图（G1）：表头**周一至周日**、日期格式**「10.20」**（F8）；左侧**周次栏全月连续**显示「第 5 周—第 9 周」（R1 学期总周数口径，不截断）；当日 10.20 高亮；右下角轻提醒「本月生日：张小雨（10.25）」（R7，课时区不重复展示）。点顶部切「**学期全景**」模式（F9）：9.1—1.17 连续滚动、无月份截断，且保留当前聚焦日期不丢位置。

**10.22（周四）右键误删 + 撤销。** 右键 10.22 下午「活动 · 教研组听评课」→ 确认删除（G2）→ 格子清空。随即发现删错了——那是明天的课！点顶部「撤销」（G3）→ 课程完整恢复。再删一次、再撤销，多步回溯无数据丢失（R5 撤销栈）。

### 2.5 期中（11 月）—— 事件管理

**11.2（周一，第 10 周）学期视图管理事件。** 切学期视图（F10）：**左侧事件类型栏 + 右侧事件列表**，按日期排序——**非日历网格**。列表里：期中考试 11.5–11.6、运动会 11.12、公开课 11.18、家长会 11.20……点开「运动会」看**五要素详情**（F11）：时间 11.12（周四）08:00–11:30 ／ 地点 学校操场 ／ 参与人员 初一(1)–(5)班全体师生 ／ 注意事项 8:00 前集合完毕、穿运动服、阴雨转室内 ／ 工作要求 梁老师 9:30 检录处裁判、提前 10 分钟到场。活动类配色默认蓝，改成紫色（F11 分类配色可改）。

**11.13（周五）。** 家长会 11.20（周五）15:30–17:00 录五要素；**精准筛选（F12）**：多选类型「活动 + 生日」→ 列表只剩两类，顶部摘要「筛选：活动 + 生日」+ 清除入口；点「**显示全部**」一键恢复全显。**批量编辑（G4）**：多选 12 月生日的 5 名学生 → 批量加备注「期末评语素材」；再批量删除 3 名已转学生的生日事件。

### 2.6 期末（1 月）—— 收官与回溯

**1.11（周一，第 20 周）。** 进度条约 96%，两端仍标「9.1 开学 / 1.17 放假」（R6）；周数「第 20 周」。今日待办自动汇总期末事务：复习课、监考、学期总结。

**1.12（周二）历史学期回溯。** 写期末总结想核对上学期运动会的确切安排——点顶部学期下拉（F1）→ 历史学期分组里选「2026 春季第二学期」→ 整个日历切到该学期数据：周/月/学期视图全部显示上学期内容，运动会五要素详情完好（G6 **学期数据隔离存储，互不覆盖**）。核对完切回「2026 秋季第一学期」，数据与离开时完全一致。

**1.15（周五）数据导出。** 用「批量导出」（I1）把本学期数据导出 CSV 备份到 U 盘。

**1.17（周日）学期收尾。** 进度条 100%，第 20 周结束。「学期总结提交」保持完成态留存，不自动删除（F2）。

### 2.7 下一学期预览（2027 年 2 月）

**2.20（周五）。** 学期管理新建**「2027年春季第二学期」**，起止日期自动带出 **2027.02.22 — 2027.07.06**（R2 联动绑定表第二条）。新学期的数据在独立隔离目录下重新生长（G6）；「2026 秋季第一学期」完整保留，随时可回溯。

## 3. 画面说明（对照示意稿）

- **左栏：DSH 原生侧栏**。原生会话列表与插件注册的顶层入口「教学日历」并存（P1 slot 注册）。点击「教学日历」进入主工作区；周/月/学期三视图是**页内顶部页签切换**（G1），侧栏不展开子菜单。
- **顶部核心信息板块（全视图常驻、固定不随内容滚动）**，分两大区（F1.1）：左侧**学期信息区**——学期下拉（含历史学期分组）、学期进度条（左右两端标注「9.1 开学 / 1.17 放假」）、周数徽标「第 20 周」；右侧**今日工作与每日文化素养区**——今日待办列表（固定课程/临时调课/个人事务自动汇总，完成=对勾+删除线，F2）与素养推送卡（类别标签 + 原文 + 白话翻译 + 通俗释义 + 「换一条」按钮，F3）。
- **中间视图内容区（独立滚动）**：周视图为 7 列星期表头（日期格内小字放生日姓名，R7）+ 每课时格子含**授课班级彩色标签 + 授课内容**双模块；月视图为周一至周日表头 + 「10.20」月日格式 + 左侧固定周次栏（全月完整）+ 右下角当月生日轻提醒；学期视图为左侧事件类型栏 + 右侧按日期排序的事件列表（非日历网格）。
- **主题切换入口**（顶部或设置区，F14）：五套主题一键切换，仅变视觉不改数据；日期底色三层级——工作日 / 周末与节假日 / 当日高亮，由主题 token 统一定义。
- 对比自建 webapp：DSH 里会话、工具、文件系统是现成的，插件只贡献数据通道 + 页面 + 渲染器；备课疑问可直接在右侧 DSH 会话面板提问（原生能力保留，日历页面本身不内嵌会话）。
