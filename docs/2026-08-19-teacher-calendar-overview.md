# 教师教学工作日历 —— 需求总览与文件索引

日期：2026-08-19
状态：v1。需求规划收官文档：全部需求清单 ↔ 对应文件 ↔ 完成状态。
后续任何实现工作以本文档为入口；需求变更时同步更新本文档。
本文档为**唯一开发标准**：所有功能逻辑、样式、交互以此为准，无额外隐性需求。

## 0. 产品一句话

道德与法治教师专用教学日历：跨年级授课（初一、小学四年级）、多班级排班备课、固定课表 + 临时调课，以 DSH 插件形态长进 Web GUI，提供周/月/学期三视图与学期数据隔离存储。

## 1. 需求清单（六大轨道 + 横切）

### 轨道 F：视图与功能（前端页面）

| 编号 | 需求 | 依赖资产 |
|------|------|---------|
| F1 | 顶部学期信息区：学期选择（标准化名称下拉）、学期进度条（左右端标注开学/放假日期）、当前周数 | D1/D2、R2/R6 |
| F2 | 今日待办任务系统：自动汇总当日固定课程/临时调课/个人事务，状态可编辑（完成=对勾+删除线，可取消），不自动删除、永久留存 | D3/D4/D5、R4 |
| F3 | 每日文化素养推送模块：教育古语/古典诗词/教育理念/教育理论/教育心理学五类，附白话翻译与通俗释义，每日自动更新+手动刷新，无重复 | C1 |
| F4 | 周视图：顶部固定显示"本学期第X周"，上下周切换（无加减按钮），单科双模块（授课班级、授课内容）解耦 | D1/D3/D4、R1/R6 |
| F5 | 班级预设管理系统：小学/初中双独立班级库，自定义名称+专属固定配色，下拉选班自动匹配颜色，禁手输、禁临时取色 | D2 |
| F6 | 课程与事务编辑：每日每节课/空白时段自由增删改替换；事务两类（课程/活动）；授课内容预设词库+手动自定义双模式 | D3/D4 |
| F7 | 调课机制：长期固定排课 vs 临时调课（仅当周生效）；课程智能顺延（中间插入后续自动后移，无冲突） | D3/D4、R3/R4 |
| F8 | 月视图：表头周一至周日、"9.1/9.2"月日格式、左侧固定周次栏（全月完整显示学期周数）、当日高亮、当月生日姓名轻提醒 | D1/D6、R1 |
| F9 | 月视图双模式：传统分页月视图 + 学期全程连续全景视图（覆盖完整学期周期，无月份截断） | D1、R1 |
| F10 | 学期视图（事件管理型）：事件列表/时间线，非日历网格；事件类型精简去重，统一归类左侧事件体系 | D5 |
| F11 | 事件详情与配色：时间/地点/参与人员/注意事项/工作要求五要素详情；各类事件专属分类配色，颜色可改 | D5 |
| F12 | 事件精准筛选：单点/多选事件类型筛选，一键恢复全显 | D5 |
| F13 | 生日事件批量管理：批量导入师生生日、批量管理生日事件 | D6、I1 |
| F14 | 主题体系：五套主题一键切换（小清新/国风/极简艺术/轻量科技/治愈暖风），仅变视觉不改数据；日期底色三层级（工作日/周末节假日/当日高亮） | D7 |

### 轨道 G：全局通用基础功能

| 编号 | 需求 | 说明 |
|------|------|------|
| G1 | 三视图自由切换 | 周/月/学期视图一键切换，流畅无卡顿 |
| G2 | 全局右键快速删除 | 所有课程、事务、生日事件支持右键删除 |
| G3 | 全局撤销/恢复 | 误删除、误修改、误新增一键回溯，防数据丢失 |
| G4 | 事件批量管理 | 单条增删改、批量导入、批量删除、批量编辑 |
| G5 | 节假日全域标注 | 所有法定节假日自动显示节日名称，无论是否放假均文字提醒 |
| G6 | 学期数据隔离存储 | 多学期独立保存、互不覆盖、永久留存、历史学期回溯查看 |

### 轨道 R：核心业务规则引擎（日历正确性护栏）

| 编号 | 需求 | 说明 |
|------|------|------|
| R1 | 周数计算：未到开学日期不显示周数不提前计数，开学后从第一周顺次累加，全站统一"学期总周数"口径 | 验收规格见规则护栏文档 |
| R2 | 学期名称-日期强制联动绑定表：2026秋季第一学期=09.01-01.17；2027春季第二学期=02.22-07.06 | 编辑学期弹窗内可改起止日期 |
| R3 | 授课内容序列顺延：某班某课时内容被替换后，该班后续内容依次顺延到其后续课时位（单班内容序列维度，仅影响该班，不影响课时槽位与其他班级） | |
| R4 | 临时调课：仅当周生效，不影响固定课表；固定排课长期复用 | |
| R5 | 撤销/恢复机制：删除/修改/新增操作入栈，支持多步回溯与恢复 | 事务性保证见规则护栏 §4 |
| R6 | 学期进度计算：实时自动更新进度百分比，进度条两端标注开学/放假日期 | 数据联动见 D1 |
| R7 | 生日展示规则：仅周视图顶部星期日期栏 + 月视图轻提醒，课时区禁重复展示 | |
