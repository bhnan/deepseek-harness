## 0. 任务一句话

在「学生成长档案工作台」班级详情页 **Tab2 成绩分析（全科学情）** 中，按「基础 6 区自动生成 + 扩展 3 图按需生成」新增成绩数据呈现能力：整体水平指标卡 / 分数段分布（直方图⇄饼图）/ 学科均衡分析 / 进退步分析 / 分层归类与临界名单 / 班级排名明细（基础区），成绩-作业联动散点图 / 单人偏科雷达图 / 分梯队多考趋势（扩展区）。全部由现有数据**自动计算**，不改变任何数据录入流程。

## 1. 背景与现状（必须基于以下事实）

- 现状 Tab2 仅有：考试管理（新增/批量录入/编辑/删除）、班级学情面板（本次考试平均分、优秀率≥85、及格率≥60、分数段 <60/60-69/70-79/80-89/≥90 条形图、较上次进退步人数）、学生列表「进/退/稳」徽标与个人波动曲线（折线）。
- 现有数据：
  - `exams`（考试：name/type/date）+ `exam_scores`（学生×科目×分数，`subject='总分'` 为总分行，含 class_rank/grade_rank），见 04 文档 §6；
  - `assignment_records`（每生每作业 status：excellent/normal/late/missing/slack/copy），见 04 文档 §7 —— **作业完成率由此实时计算，不需要新录入**。
- 现有接口（03 文档 §5，**本次尽量复用、按需向后兼容扩展**）：
  - `5.8 GET /classes/:cid/analysis?exam_id=`：exam / prev_exam / stats / subject_stats / movement / ranking。
  - `5.7 GET /students/:sid/analysis`：个人 trends（含 total/total_rank）/ status / subject_trends / weak_points。
  - `5.5 GET /exams/:eid/scores`、`5.6 GET /students/:sid/scores`：成绩明细。
  - `6.5 GET /classes/:cid/assignment-stats`：作业班级统计（复用口径参考）。
- 约定口径（沿用 03 文档 §5.8）：优秀 ≥85、及格 ≥60；单科分数段 <60/60-69/70-79/80-89/≥90；movement 对比上一次**同类型**考试。
- 数据边界（重要）：当前库**无年级成绩数据源**（仅 grade_rank 字段）。年级对比一律按"预留降级位"实现：有数据显示、无数据隐藏并提示，不阻塞主功能。

## 2. 目标页面结构（Tab2 成绩分析新布局）

```
Tab2 成绩分析（全科学情）
├─ [考试选择器] 考试▾（默认最近一次）＋ 对比开关「与上次考试对比」＋ 口径切换「总分 / 单科」
│
├─ ◆ 基础区（数据存在即自动生成，默认展开，可折叠）
│  ├─ 区块 A  整体水平指标卡（8 卡网格，带较上次差值）
│  ├─ 区块 B  分数段分布（直方图 ⇄ 饼图 模式切换，本次 vs 上次）
│  ├─ 区块 C  学科均衡分析（对比表 + 本班/年级分组柱状图 + 均分±标准差误差条图）
│  ├─ 区块 D  进退步分析（汇总卡 + 学生进退步对照表）
│  ├─ 区块 E  分层归类与临界名单（四层占比图 + 各层名单联动）
│  └─ 区块 F  班级排名明细表（条件格式热力着色 + 排序 + 导出 CSV）
│
└─ ◇ 扩展区（默认折叠，标题右侧 [一键生成] 按钮，点击后加载）
   ├─ 图表 G1  成绩-作业联动散点图（含简化分组柱状图方案）
   ├─ 图表 G2  单人偏科雷达图（弹层入口，联动 F 区与个人档案页）
   └─ 图表 G3  分梯队多考趋势折线（班级单线 ⇄ 梯队多线，分数 ⇄ 排名）
```

考试切换、口径切换、对比开关 → 基础区全区块联动刷新；扩展区数据基于同一考试上下文，切换后自动重算。

## 3. 基础区详细规格

### 区块 A · 整体水平指标卡
| 项 | 规格 |
|---|---|
| 指标 | 平均分、中位数、最高分、最低分、及格率(≥60)、优秀率(≥85)、标准差、参考人数（有总分的学生数），共 8 卡 |
| 对比 | 开启「与上次考试对比」时，每卡下方小字显示差值：`较上次 +3.2`（绿升红降灰平）；仅一次考试时不显示 |
| 切换 | 顶部口径切换「总分/单科」：选单科时 8 卡按该科成绩计算（参考人数=该科有分人数） |
| 数据 | 扩展 `5.8 stats`（见 §6），前端不自行聚合 |
| 空态 | 无成绩 → 卡片区显示「录入成绩后自动生成」（沿用现有空态样式） |

### 区块 B · 分数段分布（直方图 ⇄ 饼图）
| 项 | 规格 |
|---|---|
| 直方图（默认） | 校内学情报告场景。单科口径沿用 <60/60-69/70-79/80-89/≥90；总分口径初中默认 `<400 / 400-449 / 450-499 / 500-549 / ≥550`、小学默认 `<60 / 60-69 / 70-79 / 80-89 / ≥90`（阈值在分数线设置中可改，见区块 E）。柱上标注人数与占比 |
| 饼图（切换） | 家长会展示场景。各分数段人数占比，图例含人数与百分比；导出图片时默认带标题「XX 班 XX 考试 成绩分段占比」 |
| 对比 | 开启对比时直方图并排两组柱（本次实色、上次浅色），图例标注考试名；饼图仅展示本次 |
| 数据 | `stats.segments`（单科，已有）+ 扩展 `segments_total`（总分口径，含 prev 同口径） |

### 区块 C · 学科均衡分析
| 项 | 规格 |
|---|---|
| 对比表 | 列：科目｜平均分｜及格率｜优秀率｜标准差｜较上次均分差｜科目均分差（该科均分−本次考试全科目均分均值）｜自动徽标 |
| 徽标规则 | 均分差 ≤ −5 → 「薄弱学科」橙标；标准差为全班科目最大 → 「两极分化」紫标；均分差 ≥ +5 → 「优势学科」绿标 |
| 分组柱状图 | 每科两组柱：【本班平均分】【年级平均分】；年级数据来自可选字段 `grade_avg`——**有数据显示、无数据仅渲染本班组并提示「录入年级均分后可横向对比」**（年级数据导入另立需求，本版只留降级位） |
| 分布图（默认） | **平均分 ± 标准差误差条柱状图**：每科一根误差条柱（中点=均分，上下须=±1 标准差），通俗直观展示学科内部差距，替代复杂箱线图 |
| 箱线图（按需） | 折叠项，[展开] 后显示：每科最小/下四分位/中位数/上四分位/最大 + 离群点标注学生姓名（≤Q1−1.5IQR 或 ≥Q3+1.5IQR）；数据仅在请求带 `include_quartiles=true` 时返回（见 §6） |
| 无上次考试 | 较上次均分差列显示 `—`，不报错 |

### 区块 D · 进退步分析
| 项 | 规格 |
|---|---|
| 汇总卡 | 进步 X 人 · 退步 Y 人 · 持平 Z 人（复用 movement，另显各占比；持平=总分差绝对值 <5） |
| 对照表 | 列：姓名｜本次总分｜上次总分｜总分差（±着色）｜本次名次｜上次名次｜名次变化（上升为 +，绿色；下降为 −，红色）｜状态徽标（进/退/稳，复用现有徽标样式） |
| 排序 | 默认按名次变化降序；支持按总分差、名次变化升/降序切换 |
| 快捷筛 | 预设筛选：「退步≥10 名」「进步≥10 名」「退步≥20 分」；支持清空 |
| 对比基准 | 无上次同类型考试 → 整块显示「需 ≥2 次同类型考试」，汇总卡全 0 |
| 数据 | 扩展 `5.8` 返回 `movement_list`（每生 delta 明细，见 §6）；前端只排序筛选 |

### 区块 E · 分层归类与临界名单（对应 8 表之表 5）
| 项 | 规格 |
|---|---|
| 分数线设置 | 齿轮弹窗：总分目标线（初中默认 500，小学默认 85）、及格线（默认 = 参考科目数 × 60，可手改）、距线临界范围（默认 ±10）、分段阈值（联动区块 B 总分口径）；按班级持久化（localStorage，key=`pf_cutline_{classId}`） |
| 四层定义（严格边界） | ① 培优层：总分 ≥ 目标线 + 30；② 临界优生：总分 ∈ [目标线−10, 目标线+30)；③ 临界及格：总分 ∈ [及格线, 目标线−10)；④ 基础薄弱：总分 < 及格线 |
| 占比图 | 四层人数**饼图** + **横向条形图**双形态（默认饼图）；图例含人数与占比 |
| 名单联动 | 点击任意一层 → 下方名单表切换为该层学生：列=姓名｜总分｜距目标线分差（±着色，|差|≤5 高亮）｜各科分｜最薄弱科目（该生有分科目中「科目均分−班级该科均分」最小者）；「临界优生＋临界及格」合并即传统"临界生名单"，培优层下方单独提供「目标生名单」（总分 ∈ (目标线−30, 目标线−10)，表头注明「冲刺可及，重点跟进」） |
| 用途标注 | 区块脚注：「用于规划分层辅导师资、作业设计、课后服务安排」 |
| 数据 | 前端基于 `ranking` + `subject_stats` 计算，无需新接口 |

### 区块 F · 班级排名明细表
| 项 | 规格 |
|---|---|
| 表格 | 列：班级名次｜姓名｜学号｜总分｜各科分（每科一列，动态列）｜名次变化（较上次） |
| 条件格式 | 单元格值 ≥ 班级该科均分 → 浅绿底；≤ 均分−5 → 浅红底；总分行同规则（热力效果，一眼扫出偏科） |
| 排序 | 表头点击排序（默认总分降序）；支持按任意科排序 |
| 筛选 | 关键字（姓名/学号）过滤；「只看薄弱」开关（显示 ≥1 科低于均分 5 分以上者） |
| 弹层入口 | 点击学生名 → 弹层：个人历次总分折线（复用 5.7 trends）+ **单人偏科雷达图**（图表 G2） |
| 导出 | 导出 CSV：当前筛选结果，列=名次,姓名,学号,总分,各科…,名次变化 |
| 数据 | `ranking`（已有）+ `5.5 GET /exams/:eid/scores` 前端聚合（45 人规模直接前端合并，不新增接口） |

## 4. 扩展区详细规格（默认折叠，[一键生成] 加载）

### 图表 G1 · 成绩-作业联动散点图（对应 8 表之表 6）
| 项 | 规格 |
|---|---|
| 主方案 | 散点图：X=作业完成率（0–100%），Y=所选考试总分；叠加简单线性趋势线（前端最小二乘）；悬停显示学生姓名 |
| 完成率口径 | 该生截至考试日期前所有作业记录：status ∈ {excellent, normal, late} 计完成，{missing, slack, copy} 计未完成；完成率 = 完成数 / 已布置总数；无任何作业记录的学生不落点 |
| 简化方案 | 「完成率 0–50% / 50–80% / 80–100%」三组学生平均总分对比柱状图（零人工标注，适合常规汇报） |
| 免责原则 | 图注固定显示：「仅展示作业状态与成绩的关联，不作因果定性」（沿用 02 文档 Tab3 学情联动原则） |
| 空态 | 无作业记录 → 「在『作业台账』录入后生成」；无成绩 → 同空态 |
| 数据 | 新增 `GET /classes/:cid/analysis/assignment-link?exam_id=`（见 §6） |
| 用途标注 | 「整体学风研判：验证作业完成质量与成绩相关性」 |

### 图表 G2 · 单人偏科雷达图（对应 8 表之表 7）
| 项 | 规格 |
|---|---|
| 单人雷达图 | 维度=该生各科得分（0–100 归一），叠加**班级该科均分参考线**（虚线）→ 一眼看出瘸腿科目；入口：区块 F 学生弹层、学生个人档案页学情卡（与现有短板清单并存） |
| 全班汇总柱状图 | 统计各科「低于班级均分 ≥5 分」的学生数（每科一根柱）——偏科学生的学科分布，用于协同科任老师补差 |
| 数据 | 前端基于 `5.5 scores` + `subject_stats` 计算，无需新接口 |
| 用途标注 | 「个性化辅导方案制定，协同科任补差」 |

### 图表 G3 · 分梯队多考趋势折线（对应 8 表之表 8）
| 项 | 规格 |
|---|---|
| 模式 | ① 班级均分单线（默认）；② 分梯队多线：按**历次考试总分排名分位**将学生分为 前 25% / 中 50% / 后 25% 三组（人数取 ceil(n×0.25) 前组、ceil(n×0.25) 后组、其余中组），每组各画一条历次总分均分折线——观察培优层与后进生整学期走势是否**分化**（顶部上升+底部下滑 = 最需干预信号） |
| 口径切换 | 分数 ⇄ 排名（排名=各组总分名次均值）；目标线横向虚线（开启时） |
| 悬停 | 显示考试名/日期/该线数值 |
| 仅一次考试 | 显示单点，标注「仅 1 次考试」 |
| 数据 | 扩展 `GET /classes/:cid/analysis/trends`（见 §6） |
| 用途标注 | 「学期整体复盘、期末总结、学年归档」 |

## 5. 出图策略（防信息过载）

1. **基础区 6 区块**：考试数据存在即自动生成，默认展开；区块标题右侧折叠按钮。
2. **扩展区 3 图表**：默认整体折叠为一行「扩展图表（按需生成）」；每图标题右侧 [一键生成] / [收起] 按钮，点击才加载渲染。
3. 区块 C 的**箱线图默认隐藏**（折叠项），默认只显示误差条柱状图。
4. 图表右上角统一提供 [导出图片]（PNG，Canvas/SVG 序列化），供汇报材料使用。
5. 可选增强（P2，可后置）：整页「学情报告」打印友好视图（图+表一体，浏览器打印为 PDF），入口在 Tab2 右上角「导出报告」。

## 6. 接口扩展清单（03 文档增量，全部向后兼容）

| 接口 | 扩展内容 |

| 降级规则 | 所有新增字段缺失/为空时前端正常渲染（`—` 或空态），**旧版接口响应不得导致页面报错** |

## 7. 交互与体验约束

1. 考试切换、口径切换、对比开关 → 全区块联动刷新；加载中显示轻量骨架（沿用现有 loading 样式）。
2. 「±着色」统一：升/进步 = 绿（#4CAF50 系），降/退步 = 红（#E53935 系），持平 = 灰；**同时用 ▲/▼/＝ 字符或文字徽标辅助**（色觉友好，不单靠颜色）。
3. 数字精度：比率保留 2 位小数；分数保留 1 位小数。
4. 表格行数较多（区块 D/F）表头吸顶；区块间不互相遮挡。
5. 图表风格约束：**优先柱状图/直方图/饼图/折线图等学校汇报通用、简洁易懂类型；雷达/散点/误差条为进阶；禁止 3D、双轴、面积渐变等花哨效果**。
6. 图表实现：沿用项目现有图表方案；若无图表库，柱/饼/折线可用纯 CSS/SVG，散点/雷达允许引入轻量图表库（如 ECharts 按需加载）或手写 SVG——不引入重型框架，首屏加载不显著变慢。
7. 主题适配：三套主题（fresh #4A90D9 / pastel #7FB069 / art #8C6E4A）下图表主色与强调色随主题切换，表格样式走 CSS 变量。
