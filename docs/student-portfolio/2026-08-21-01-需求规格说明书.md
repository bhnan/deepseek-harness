## 1. 文档目的与范围

本说明书将原始需求（《AI搭建教师专属学生信息与成长档案工作台指令》）转换为结构化的、可开发、可测试、可验收的需求规格。全文覆盖：

- 验收标准

## 2. 产品定位

**学生成长档案工作台** 是梁老师专属的单机教师工作台，与现有「教师教学日历」并列运行、互不依赖（两个独立应用、两个独立 DSH 启动按钮），二者**唯一联动**为：成长档案工作台中创建的「沟通安排」（谈心 / 家访 / 家长约谈 / 私聊安排）单向同步为教学日历中的事件，除此之外无任何数据互通。

产品核心宗旨：**减负、自动化、可追溯、精准育人、高效家校沟通**。严格区分【初中班主任主班全功能板块】与【道法代课班精简学科板块】，支持小学、初中跨学段隔离管理与一键切换。教师知识库与每日推送为**轻量辅助模块**——以顶部常驻「知识卡片」呈现（形态同教学日历的名言古语卡片），**不设独立板块**。

## 3. 角色与权限模型

| 角色 | 说明 | 权限 |
|---|---|---|
| 梁老师（唯一用户） | 班主任 + 道法代课老师 | 全功能；隐私数据仅本人可见（本机运行 + 敏感字段加密） |
| 系统（自动化） | 统计、分析、评语生成、分层、推送 | 只读计算，不擅自修改用户数据（评语/分层结果需用户确认后落库或标注 source=auto） |

无多用户/账号体系。无角色权限细分。

## 4. 术语表

| 术语 | 定义 |
|---|---|
| 学段 stage | `primary`=小学，`middle`=初中 |
| 板块 role | `homeroom`=班主任主班（全功能档案），`subject`=道法代课班（学科精简档案） |
| 主班 | 梁老师全职班主任的 1 个初中班级，享全功能板块；**自动纳入道法学科多班对比分析** |
| 代课班 | 道法代课班级，仅保留学科所需功能 |
| 学期 | 秋季学期 09-01 ~ 次年 01-31；春季学期 02-01 ~ 07-31（素材归档、复盘、时间线筛选的默认口径） |
| 沟通安排 | 谈心、家访、家长约谈、私聊安排等事件；唯一联动日历的数据对象 |
| 知识卡片 | 顶部常驻轻量卡片：当日推送（4 类标签可切换）+「换一条」+ 点击展开全文 + 收藏/笔记；呈现形态与教学日历「名言古语」卡片一致 |
| 敏感字段 | 身份证号、家庭住址、家长电话、家庭特殊情况等，一律 AES-256-GCM 加密落盘 |

## 5. 功能需求

### 5.1 全局通用基础设置（FR-1，全学段、全班级统一生效）

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-1.1 | 跨学段层级分类 | 三级归档结构「学段 → 年级 → 班级」；固定划分两大板块：班主任主班（全功能）、道法代课班（精简）；小学/初中数据严格隔离、互不串档 |
| FR-1.2 | 班级管理 | 手动增删班级、改名、编辑学段归属与板块归属；一键筛选「全部 / 小学 / 初中」快速切换查看对应学段全部班级 |
| FR-1.3 | 学生成长素材归档 | 全班级、全学生统一多媒体素材归档：上传、分类储存、随时预览导出；含课堂表现、运动会、活动实践、日常风采、获奖证书、班级荣誉、活动合影；支持标注时间与事件备注；**按学期自动归档**，形成可视化成长轨迹 |
| FR-1.4 | 全域智能评语生成 | 基于成绩进退步、作业状态、课堂表现、品德心理、社交相处、特长短板多维数据，自动生成三类文案：①师生一对一谈心话术 ②家校沟通评语 ③阶段性综合素质评语；支持手动修改、保存、复用、导出 |
| FR-1.5 | 全自动数据更新与回溯 | 成绩、作业、德育、心理、素材档案实时自动同步更新；生成学生个人成长时间线，支持按学期、学年、自定义时间段筛选回溯 |
| FR-1.6 | 自定义界面与多风格切换 | 默认标题「梁老师的学生成长档案」，可编辑教师姓名与整体标题；内置简约风、小清新风、艺术风等多视觉主题一键切换 |
| FR-1.7 | 通用基础保障 | 全域数据一键导出、打印、备份；学生隐私信息加密保护仅本人可查看；全程轻量化运行 |

### 5.2 初中班主任主班板块（FR-2，全功能）

#### （一）学生完整基础信息（FR-2.1）

| 编号 | 需求 |
|---|---|

| FR-2.1.2 | 特殊备注字段：家庭特殊情况（单亲、留守、经济困难、家庭矛盾等）、学生体质过敏史、日常管理注意事项（均加密存储） |
| FR-2.1.3 | 初中专属字段：青春期状态、升学目标、住校情况、学业压力等级（低/中/高） |

| 编号 | 需求 |
|---|---|
| FR-2.2.1 | 考试类型全覆盖：分班测试、周考、月考、期中、期末、模拟考、专项测试；支持表格批量导入，数据永久留存 |
| FR-2.2.2 | 全科数据：各学科分数、班级排名、年级排名、总分、总排名自动收录 |
| FR-2.2.3 | 智能进退步分析：自动对比历次考试，标注单科/总分进退步幅度，生成个人成绩波动曲线、阶段性学情趋势图；标注稳定/进步/退步/波动状态 |

结合全科学情、作业状态、品德心理、社交表现、优缺点短板，自动生成高适配文案：师生谈心疏导话术、精准家校沟通评语、期末综合素质评语；支持自定义修改、长期复用（FR-1.4 的主班落地形态）。

### 5.5 教师知识库 + 每日推送（FR-5，轻量辅助模块）

> **定位（定稿调整）**：知识库为**辅助功能，不作为独立板块**。知识内容以**顶部常驻「知识卡片」**呈现——单条显示、4 类标签切换、「换一条」刷新、点击展开全文、卡片内收藏/笔记，形态与教学日历中的「名言古语」卡片完全一致，不占主界面。

| 编号 | 需求 |
|---|---|
| FR-5.1.1 | 教育名著精华库：《给教师的建议》《班主任工作漫谈》《爱心与教育》《第56号教室的奇迹》《什么是教育》《民主主义与教育》《教育的目的》等，只保留一线可落地技巧 |
| FR-5.1.2 | 学段心理专项库：小学儿童心理、初中青春期心理两大体系；覆盖习惯养成、情绪疏导、厌学干预、叛逆引导、同伴社交、学业减压、亲子沟通 |
| FR-5.1.3 | 名师实操经验库：班主任带班干货、问题学生转化、班风建设、家校沟通案例；道法教师跨学段教学、分层授课、德育渗透、时政融合、作业设计经验 |
| FR-5.1.4 | 教育家金句理念库：古今中外教育家名言与育人理念，搭配通俗解读，可直接用于班级寄语、家校文案、育人反思、学生谈心 |
| FR-5.2 | 知识卡片呈现：顶部常驻一张卡片，默认显示当日推送 1 条；卡片上可切换 4 类标签（班主任干货 / 道法干货 / 心理实操 / 金句）、点「换一条」手动刷新（按日期键控去重）、点击展开全文；收藏与笔记操作收敛在卡片内；**无独立板块页面** |
| FR-5.3 | 每日固定推送 4 类（每类每日 1 条）：①班主任管理干货 ②道法教学德育干货（区分小学/初中）③教育心理学实操知识点+落地话术 ④教育家金句+通俗解读；按日期去重、开机即看 |
| FR-5.4 | 学期节点智能适配：开学立规、日常学风管控、期中期末学情复盘、考前心态疏导、假期安全与自律管理、初中青春期专项引导（调整各类推送的优先权重） |
| FR-5.5 | 轻量复用闭环：卡片内一键收藏、记笔记；内容可一键转化为谈心话术、家长群通知文案（复制使用）；长期沉淀个人育人资源 |
| FR-5.6 | 轻量检索与复盘：卡片展开区或全局设置页内提供知识库关键词检索（内容按七大分类目录组织：班级常规管理、问题学生专项疏导、跨学段育人指导、家校沟通体系、道法学科专属教学、学生心理健康教育、教师自我成长）；按周/月/学期自动汇总推送精华与收藏笔记，生成学习台账、德育工作小结，一键导出（教研总结、师德考核、职称材料） |

### 5.6 知识库与教学日历的隔离约定（FR-6，重要约束）

| 编号 | 约定 |
|---|---|
| FR-6.1 | 教学日历继续展示原有「名言古语」推送；成长档案工作台展示**独立**的教育名著精华库、学段心理专项库、名师实操经验库、教育家金句理念库；两库互不复用、互不同步 |
| FR-6.2 | 两个应用各自独立建库、独立备份、独立导出 |

### 5.7 与教学日历的唯一联动（FR-7）

| 编号 | 需求 |
|---|---|
| FR-7.1 | 成长档案工作台创建的「沟通安排」（类型：talk 谈心 / home_visit 家访 / parent_meet 家长约谈 / chat 私聊安排）**单向同步**为教学日历事件（type=activity） |
| FR-7.2 | 同步规则：目标学期由沟通日期自动匹配教学日历学期（`start_date ≤ date ≤ end_date`）；匹配失败则使用配置的兜底学期；同步结果回写（成功记录 calendar_event_id；失败可手动重试） |
| FR-7.3 | 除 FR-7.1 外无任何其他联动（不读日历班级、不读日历作业、不读日历考试） |

## 6. 非功能需求

| 编号 | 需求 | 指标 |
|---|---|---|
| NFR-1 | 性能 | 常规页面加载 ≤ 2s；单班 50 名学生、20 次考试规模下，学情分析接口 ≤ 500ms |
| NFR-2 | 数据一致性 | SQLite 事务保证原子性；外键 + 唯一约束防脏数据；schema 版本管理（schema_version 表）；所有接口输入强校验 |
| NFR-3 | 隐私安全 | 敏感字段 AES-256-GCM 加密落盘（密文格式 `v1:<iv>:<cipher>`）；密钥本地文件（权限 600）；导出支持脱敏选项 |
| NFR-4 | 可追溯 | 全局撤销/重做栈；操作可回滚；数据修改时间戳留存 |
| NFR-5 | 备份 | 一键备份（数据库 + 素材文件打包），一键恢复 |
| NFR-6 | 轻量化 | 单机运行；无外部服务依赖（除联动目标教学日历 API）；SQLite 使用 Node 内置模块，零新增原生依赖 |
| NFR-7 | 可移植 | 前端 Vite 构建，API Express；与教学日历同构，复用现有 DSH 桥接插件方案（热插拔） |

## 7. 全局设计约束（技术选型，定稿）

| 项 | 决策 |
|---|---|
| 存储 | **SQLite 单文件** `data/student-portfolio.db`（Node 内置 `node:sqlite` DatabaseSync；WAL 模式；外键开启；UTF-8） |
| 后端 | Express（独立端口 **8797**），与教学日历（8787）并行 |
| 前端 | Vite（端口 **5174**）+ React，复用教学日历同款构建方式 |
| DSH 集成 | 独立桥接插件（`@bhn/teacher-portfolio-bridge`），侧栏独立按钮（📁 成长档案），热插拔 |
| ID 生成 | `pf_<实体前缀>_<20位随机hex>` |
| 日期格式 | `YYYY-MM-DD`（全系统唯一形态）；时间自由文本或 `HH:mm`；时间戳 ISO 8601 UTC |
| 响应格式 | 成功 `{ok:true, ...}`；失败 HTTP 4xx/5xx + `{ok:false, reason}` |
| 撤销 | 全局 undo/redo 栈（JSON 快照式，与教学日历一致） |
| 加密 | AES-256-GCM，密钥文件 `data/_global/portfolio_secret.json`（不存在则首次启动生成，chmod 600） |
| 联动目标 | 教学日历 `http://127.0.0.1:8787`（地址在设置中可配置） |

## 8. 验收标准（总）

1. 两大板块（主班全功能 / 代课精简）导航清晰 + 顶部知识卡片可见，学段一键筛选可用，小学/初中数据互不串档（抽查任一学生数据，跨学段检索无命中）。
2. 班级/学生增删改、CSV 批量导入、导出、打印可用；敏感字段导出默认脱敏。
3. 成绩批量导入后：个人进退步/波动曲线/短板清单、班级平均分/优秀率/及格率/分数段自动生成且数字与手工核算一致。
4. 作业台账周/月/学期统计自动生成；作业态度与成绩联动分析可用。
5. 德育心理记录按学期自动汇总，可生成德育综合素质报告。
6. 素材上传/分类/预览/导出可用，自动按学期归档。
7. 评语三类自动生成，可修改/保存/复用/导出。
8. 话术库双学段双语气模板齐全，占位符替换正确。
9. 道法板块：多班对比、个人进退步、题型短板、自动分层（可人工微调）、分层配套方案可用；主班自动纳入对比。
10. 顶部知识卡片可用：4 类标签切换、「换一条」（按日期去重）、展开全文、收藏/笔记；轻量检索与周/月/学期复盘导出可用（入口不占主界面）。
11. 沟通安排创建 → 教学日历事件出现（正确学期、正确标题/日期）；同步失败可重试；无其他数据互通（对照 FR-7）。
12. 一键备份/恢复可用；撤销/重做覆盖主要写操作。
13. 隐私字段在数据库文件中不可读（密文）；密钥文件权限 600。
14. 全部接口遵循 03 接口设计文档的 schema，前后端字段命名一致。

## 9. 明确不做（Out of Scope）

- 不做多用户/登录/权限体系（单机单用户）。
- 不做与教学日历的双向同步（日历改事件不回写档案）。
- 不做短信/微信真实发送（话术仅生成文案，复制到家长群使用）。
- 不做 AI 大模型在线生成（评语/话术由本地规则引擎生成，确定性、可追溯、零成本）。
- 不做移动端 App（浏览器访问）。
