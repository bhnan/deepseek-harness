## 4. 班级表

```sql
CREATE TABLE IF NOT EXISTS classes (
  id          TEXT PRIMARY KEY,            -- pf_cls_...
  name        TEXT NOT NULL UNIQUE,        -- 班级名，唯一（全校唯一）
  grade       TEXT NOT NULL,               -- 年级，如 初一 / 四年级
  stage       TEXT NOT NULL CHECK (stage IN ('primary','middle')),

  updated_at  TEXT NOT NULL

```

## 5. 学生表

```sql
CREATE TABLE IF NOT EXISTS students (
  id             TEXT PRIMARY KEY,         -- pf_stu_...
  class_id       TEXT NOT NULL REFERENCES classes(id) ON DELETE CASCADE,
  name           TEXT NOT NULL,
  student_no     TEXT NOT NULL DEFAULT '', -- 学号（班级内唯一，见索引）
  gender         TEXT CHECK (gender IN ('男','女')),
  birth_date     TEXT,                     -- YYYY-MM-DD
  school_id      TEXT NOT NULL DEFAULT '', -- 学籍号
  -- ↓ 敏感字段：一律密文存储（v1:<iv>:<cipher>），空串 = 未填
  id_card        TEXT NOT NULL DEFAULT '', -- 身份证号（加密）
  address        TEXT NOT NULL DEFAULT '', -- 家庭住址（加密）
  parent1_name   TEXT NOT NULL DEFAULT '', -- 家长1 姓名（加密）
  parent1_phone  TEXT NOT NULL DEFAULT '', -- 家长1 电话（加密）
  parent2_name   TEXT NOT NULL DEFAULT '', -- 家长2 姓名（加密）
  parent2_phone  TEXT NOT NULL DEFAULT '', -- 家长2 电话（加密）
  guardian_note  TEXT NOT NULL DEFAULT '', -- 监护人备注（加密）
  special_note   TEXT NOT NULL DEFAULT '', -- 家庭特殊情况（加密）
  allergy_note   TEXT NOT NULL DEFAULT '', -- 体质过敏史（加密）
  manage_note    TEXT NOT NULL DEFAULT '', -- 管理注意事项（加密）
  -- ↓ 非敏感字段
  is_boarding    INTEGER NOT NULL DEFAULT 0,  -- 0 走读 / 1 住校
  pressure_level TEXT NOT NULL DEFAULT '中' CHECK (pressure_level IN ('低','中','高')),
  puberty_status TEXT NOT NULL DEFAULT '', -- 青春期状态（初中）
  goal_note      TEXT NOT NULL DEFAULT '', -- 升学目标（初中）
  subject_note   TEXT NOT NULL DEFAULT '', -- 道法学科备注（代课班专用，主班可留空）
  active         INTEGER NOT NULL DEFAULT 1,  -- 1 在用 / 0 停用（不物理删除）
  created_at     TEXT NOT NULL,
  updated_at     TEXT NOT NULL
);
CREATE UNIQUE INDEX IF NOT EXISTS idx_students_no ON students(class_id, student_no) WHERE student_no <> '';
CREATE INDEX IF NOT EXISTS idx_students_class ON students(class_id, active);
```
> 代课班（role=subject）学生仅使用：id/class_id/name/student_no/subject_note/active/created_at/updated_at；其余字段一律不录入（写入时忽略并告警，见接口 4.2）。

## 6. 成绩域

```sql
CREATE TABLE IF NOT EXISTS exams (
  id          TEXT PRIMARY KEY,            -- pf_exm_...
  class_id    TEXT NOT NULL REFERENCES classes(id) ON DELETE CASCADE,
  name        TEXT NOT NULL,
  type        TEXT NOT NULL CHECK (type IN ('placement','weekly','monthly','midterm','final','mock','subject','other')),
  date        TEXT NOT NULL,               -- YYYY-MM-DD
  note        TEXT NOT NULL DEFAULT '',
  created_at  TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_exams_class_date ON exams(class_id, date DESC);

CREATE TABLE IF NOT EXISTS exam_scores (
  id            TEXT PRIMARY KEY,          -- pf_scr_...
  exam_id       TEXT NOT NULL REFERENCES exams(id) ON DELETE CASCADE,
  student_id    TEXT NOT NULL REFERENCES students(id) ON DELETE CASCADE,
  subject       TEXT NOT NULL,             -- 科目枚举，subject='总分' 为总分行
  score         REAL NOT NULL,             -- 分数（科目 0-100；总分不限）
  class_rank    INTEGER,                   -- 班级排名（正序，1 起；NULL=未录）
  grade_rank    INTEGER,                   -- 年级排名
  question_scores TEXT,                    -- JSON：{"选择":12,"简答":8}（仅道法题型诊断）
  created_at    TEXT NOT NULL,
  updated_at    TEXT NOT NULL,
  UNIQUE (exam_id, student_id, subject)    -- 覆盖式 upsert 依据
);
CREATE INDEX IF NOT EXISTS idx_scores_exam ON exam_scores(exam_id);
CREATE INDEX IF NOT EXISTS idx_scores_student ON exam_scores(student_id, subject);
```
> `question_scores` 题型 key 固定集合：`选择` `简答` `材料分析` `论述`（道法）；其他科目可空对象 `{}`。失分率计算 = 1 − 得分/满分，满分口径：选择 20 / 简答 10 / 材料分析 8 / 论述 6（单科总分 44，仅供相对比较；若班级实际卷面不同，前端提示"按标准卷面口径估算"）。——此条在 06 文档注明口径可配置。

## 13. 分层域（道法）

```sql
CREATE TABLE IF NOT EXISTS layers_snapshot (
  id          TEXT PRIMARY KEY,            -- pf_lay_...
  class_id    TEXT NOT NULL REFERENCES classes(id) ON DELETE CASCADE,
  stage       TEXT NOT NULL CHECK (stage IN ('primary','middle')),  -- 分层时学段口径
  rule_json   TEXT NOT NULL,               -- {"weight":{"score":0.6,"question":0.25,"classroom":0.15},"stage":"middle"}
  created_at  TEXT NOT NULL,
  updated_at  TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_layers_class ON layers_snapshot(class_id);

CREATE TABLE IF NOT EXISTS student_layers (
  id          TEXT PRIMARY KEY,            -- pf_sl_...
  class_id    TEXT NOT NULL REFERENCES classes(id) ON DELETE CASCADE,
  student_id  TEXT NOT NULL REFERENCES students(id) ON DELETE CASCADE,
  layer       TEXT NOT NULL CHECK (layer IN ('advanced','middle','basic')),
  source      TEXT NOT NULL CHECK (source IN ('auto','manual')),
  updated_at  TEXT NOT NULL,
  UNIQUE (class_id, student_id)
);
CREATE INDEX IF NOT EXISTS idx_sl_class ON student_layers(class_id, layer);
```
> 分层计算输入（固定口径）：`score` = 该班最近一次考试（优先 midterm/final/monthly，其次任意类型）道法平均分（0-100 归一）；`question` = 最近一次含题型数据的考试失分率（高失分 → 低分）；`classroom` = 最近 30 天作业记录折算（excellent=100, normal=80, late=60, slack=30, missing=0, copy=0 取均值）。总分 = score×0.6 + question×0.25 + classroom×0.15；阈值：≥80 培优 / 60-79 中等 / <60 基础。小学口径权重（score 0.5 / classroom 0.35 / question 0.15），阈值 ≥85 / 65-84 / <65。分层快照可整体撤销（入撤销栈）。

## 15. 知识库与推送域（顶部知识卡片数据源）

> 定位（定稿调整）：本域仅服务顶部「知识卡片」（单条呈现 + 4 类切换 + 换一条）与轻量检索/复盘；表结构不变，无独立板块页面。

```sql
CREATE TABLE IF NOT EXISTS knowledge_items (
  id          TEXT PRIMARY KEY,            -- pf_ki_...
  library     TEXT NOT NULL CHECK (library IN ('classic','psychology','master','quote')),
  category    TEXT NOT NULL CHECK (category IN ('class_management','problem_student','cross_stage','home_school','df_teaching','mental_health','self_growth')),
  stage       TEXT NOT NULL DEFAULT 'all' CHECK (stage IN ('all','primary','middle')),
  title       TEXT NOT NULL,
  content     TEXT NOT NULL,               -- 正文（≤8000 字）
  source      TEXT NOT NULL DEFAULT '',    -- 出处（书名/人名/文章）
  tags        TEXT NOT NULL DEFAULT '[]',  -- JSON 数组字符串
  favorite    INTEGER NOT NULL DEFAULT 0,
  note        TEXT NOT NULL DEFAULT '',    -- 个人笔记
  created_at  TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_ki_lib ON knowledge_items(library, category);
CREATE INDEX IF NOT EXISTS idx_ki_fav ON knowledge_items(favorite);

CREATE TABLE IF NOT EXISTS push_logs (
  date        TEXT NOT NULL,               -- YYYY-MM-DD
  kind        TEXT NOT NULL CHECK (kind IN ('manager','df_teaching','psychology','quote')),
  item_id     TEXT NOT NULL REFERENCES knowledge_items(id) ON DELETE CASCADE,
  round       INTEGER NOT NULL DEFAULT 1,  -- 全库轮次（推完一轮 +1）
  PRIMARY KEY (date, kind)                 -- 每天每类唯一（去重键控）
);
```
> 每日推送规则（固定）：每类取 `push_logs` 中未被推过的该库条目随机一条；全部推完 → round+1 重置；`df_teaching` 优先取 stage 匹配当前学段偏好（settings.stage_filter 或 默认 middle）的条目，`all` 通用。

## 16. 撤销域

```sql
CREATE TABLE IF NOT EXISTS undo_log (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  op          TEXT NOT NULL,               -- create / update / delete / batch
  entity      TEXT NOT NULL,               -- 实体名（见接口文档 §15.1 清单）
  entity_id   TEXT NOT NULL,
  before_json TEXT,                        -- 操作前快照（JSON，全量）
  after_json  TEXT,                        -- 操作后快照（JSON，全量）
  ts          TEXT NOT NULL
);
```
- 撤销 = 取栈顶 entry 回放 before_json；重做 = 回放 after_json。
- 批量实体（student_import/exam_scores_batch/assignment_records_batch/layers_auto）before/after 为受影响行数组的 JSON。
- 跨实体关联撤销：删除班级/考试/作业 → before_json 含级联实体数组（按 `{"entity":"class","rows":[...]}` 结构），回放时按序恢复。

## 17. 素材文件存储约定

- 根目录：`data/uploads/`
- 子目录：`<YYYYMM>/`（上传月份）
- 文件名：`<material_id>.<ext>`（ext 由 mime 映射：jpeg→jpg, png, gif, webp, mp4, pdf, doc, docx, xlsx, zip）
- 删除素材：物理文件 + 数据库行同步删除。
- 备份包结构：`student-portfolio.db` + `uploads/` + `manifest.json`（`{"app":"student-portfolio","schema_version":1,"created_at":...}`）。

## 18. 索引与约束总表（一致性保障）

| 保障 | 实现 |
|---|---|
| 班级名唯一 | classes.name UNIQUE |
| 学号班级内唯一 | idx_students_no 部分唯一索引 |
| 成绩幂等 | exam_scores UNIQUE(exam_id, student_id, subject) |
| 作业记录幂等 | assignment_records UNIQUE(assignment_id, student_id) |
| 分层幂等 | student_layers UNIQUE(class_id, student_id) |
| 推送每日去重 | push_logs PRIMARY KEY(date, kind) |
| 荣誉归属 | honors CHECK(student_id 或 class_id 至少其一) |
| 素材归属 | materials CHECK(owner 与学生/班级匹配) |
| 引用完整性 | 全部外键 ON DELETE CASCADE（materials→honors 为 SET NULL） |
| 枚举防漂移 | 全部 CHECK 约束（与接口文档 §1.7 一致） |
| 事务 | 所有写操作包在单个事务中（BEGIN…COMMIT/ROLLBACK）；批量接口整批原子 |

## 19. 加密实现规范（固定）

- 算法：AES-256-GCM；密钥 32 字节随机；iv 12 字节随机；附加认证数据 AAD = `"student-portfolio:v1"`。
- 密文格式：`v1:<iv_base64url>:<cipher_base64url>`。
- 密钥文件：`data/_global/portfolio_secret.json` → `{"version":1,"key":"<base64 32B>","created_at":"..."}`，写入后 `chmod 600`；不存在则首次启动自动生成。
- 解密失败（密钥缺失/损坏）→ 接口返回 ENCRYPT_ERROR，禁止静默返回空串。
- 加密字段全集（固定）：students.id_card / address / parent1_name / parent1_phone / parent2_name / parent2_phone / guardian_note / special_note / allergy_note / manage_note。
- 导出脱敏规则（固定）：身份证 `前3 + **** + 后4`；手机 `前3 + **** + 后4`；地址保留省市 + `****`；家长姓名 `姓 + **`。
