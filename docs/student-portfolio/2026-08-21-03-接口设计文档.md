# 学生成长档案工作台 · 接口设计文档（定稿版）

> 文档编号：PF-API-2026-08-21 ｜ 版本：v1.0（定稿）
> 本文件为**唯一接口契约**：前后端、测试、数据结构均以此为准。schema 全程固定，任何字段变更必须升版本号并同步本文档。

---

## 1. 全局约定

### 1.1 基础信息
| 项 | 值 |
|---|---|
| Base URL | `http://127.0.0.1:8797/api/portfolio` |
| 鉴权 | 无（单机单用户；仅本机监听 127.0.0.1） |
| 请求体 | `application/json; charset=utf-8`；上传接口 `multipart/form-data` |
| 字符集 | UTF-8 |

### 1.2 响应格式（固定）
- 成功：`HTTP 200`，`{ "ok": true, ...业务字段 }`
- 失败：`HTTP 4xx/5xx`，`{ "ok": false, "reason": "<中文原因>" }`

### 1.3 错误码（固定枚举）
| code | HTTP | 含义 |
|---|---|---|
| `BAD_REQUEST` | 400 | 参数缺失/格式非法（reason 说明具体字段） |
| `NOT_FOUND` | 404 | 资源不存在 |
| `CONFLICT` | 409 | 唯一性冲突（重名/重复录入） |
| `ENCRYPT_ERROR` | 500 | 加密/解密失败 |
| `SYNC_ERROR` | 502 | 联动教学日历失败（reason 含目标接口与原因） |
| `INTERNAL` | 500 | 未预期错误 |

### 1.4 标识与格式约定
| 项 | 规则 |
|---|---|
| ID | `pf_<前缀>_<20位随机hex>`；前缀：`cls`班级 `stu`学生 `exm`考试 `scr`成绩 `aw`作业 `arec`作业记录 `mr`德育 `tl`特长 `hn`荣誉 `mat`素材 `cmt`评语 `ph`话术 `lay`分层 `sl`学生分层 `com`沟通 `ki`知识条目 `bak`备份 |
| 日期 | `YYYY-MM-DD`（严格正则 `^\d{4}-\d{2}-\d{2}$` 且为合法日期） |
| 时间 | 自由文本（如 `15:30` / `下班前`），≤ 50 字符；空串 = 未填 |
| 时间戳 | ISO 8601 UTC（`new Date().toISOString()`） |
| 布尔 | `true/false` |
| 金额/分数 | `REAL`；百分比由前端计算展示（接口返回原始计数与总数） |

### 1.5 分页（列表接口统一支持，可选参数）
`?page=1&page_size=50` → 响应附 `{ "total": n, "page": 1, "page_size": 50 }`；缺省 page=1, page_size=100（上限 500）。

### 1.6 加密字段传输约定（重要）
- 写入：客户端**明文**提交敏感字段（本机回环，安全）；服务端加密后落库。
- 读取：列表接口默认**脱敏**返回（`id_card: "420***********1234"`，`phone: "138****5678"`，`address: "湖北省武汉市****"`）；单个学生详情接口（`GET /students/:sid`）返回**明文**（仅本人使用）。
- 加密格式：密文存储 `v1:<iv_base64>:<cipher_base64>`；算法 AES-256-GCM。

### 1.7 枚举定义（全文统一引用，禁止漂移）

**stage（学段）**：`primary` 小学 ｜ `middle` 初中
**role（板块）**：`homeroom` 班主任主班 ｜ `subject` 道法代课班
**gender**：`男` ｜ `女`
**pressure_level（学业压力）**：`低` ｜ `中` ｜ `高`
**exam_type（考试类型）**：`placement` 分班测试 ｜ `weekly` 周考 ｜ `monthly` 月考 ｜ `midterm` 期中 ｜ `final` 期末 ｜ `mock` 模拟考 ｜ `subject` 专项测试 ｜ `other` 其他
**hw_status（作业状态）**：`excellent` 优质完成 ｜ `normal` 正常完成 ｜ `late` 补交 ｜ `missing` 缺交 ｜ `slack` 敷衍 ｜ `copy` 抄袭
**moral_category（德育类别）**：`emotion` 情绪心理 ｜ `family` 家庭动态 ｜ `relationship` 人际关系 ｜ `conduct` 思想品德 ｜ `reward` 奖励 ｜ `punish` 违纪 ｜ `volunteer` 志愿服务 ｜ `other` 其他
**honor_level（荣誉级别）**：`school` 校级 ｜ `district` 区级 ｜ `city` 市级 ｜ `province` 省级 ｜ `national` 国家级
**material_category（素材分类）**：`class_performance` 课堂表现 ｜ `sports` 运动会 ｜ `activity` 活动实践 ｜ `daily` 日常风采 ｜ `award_cert` 获奖证书 ｜ `class_honor` 班级荣誉 ｜ `photo` 活动合影 ｜ `df_activity` 道法学科活动 ｜ `df_honor` 道法学科表彰 ｜ `other` 其他
**comment_type（评语类型）**：`talk` 谈心话术 ｜ `home_school` 家校沟通评语 ｜ `periodic` 综合素质评语
**phrase_category（话术分类）**：`homework` 作业布置 ｜ `supervise` 家校监督 ｜ `safety` 安全专项 ｜ `material` 物资携带 ｜ `custom` 自定义
**tone（语气）**：`strict` 严谨 ｜ `gentle` 温和
**layer（分层）**：`advanced` 培优层 ｜ `middle` 中等提升层 ｜ `basic` 基础补差层
**layer_source**：`auto` 自动 ｜ `manual` 人工微调
**com_type（沟通安排类型）**：`talk` 谈心 ｜ `home_visit` 家访 ｜ `parent_meet` 家长约谈 ｜ `chat` 私聊安排
**sync_status（联动状态）**：`pending` 待同步 ｜ `synced` 已同步 ｜ `failed` 同步失败
**library（知识库）**：`classic` 教育名著精华库 ｜ `psychology` 学段心理专项库 ｜ `master` 名师实操经验库 ｜ `quote` 教育家金句理念库
**knowledge_category（七大目录）**：`class_management` 班级常规管理 ｜ `problem_student` 问题学生专项疏导 ｜ `cross_stage` 跨学段育人指导 ｜ `home_school` 家校沟通体系 ｜ `df_teaching` 道法学科专属教学 ｜ `mental_health` 学生心理健康教育 ｜ `self_growth` 教师自我成长
**push_kind（每日推送类）**：`manager` 班主任管理干货 ｜ `df_teaching` 道法教学德育干货 ｜ `psychology` 心理学实操 ｜ `quote` 教育家金句
**subject（科目，固定 + 可扩展）**：`语文` ｜ `数学` ｜ `英语` ｜ `道德与法治` ｜ `历史` ｜ `地理` ｜ `生物` ｜ `物理` ｜ `化学` ｜ `总分`；允许自定义科目名（≤10 字），自定义科目不参与跨班对比的固定口径（仅本班统计）。

## 2. 设置接口

### 2.1 GET /settings
获取全局设置。
响应：
```json
{ "ok": true, "settings": {
  "title": "梁老师的学生成长档案",
  "teacher_name": "梁老师",
  "theme_id": "fresh",
  "stage_filter": "all",
  "calendar_api_base": "http://127.0.0.1:8787",
  "calendar_semester_id": "2026-autumn-1",
  "calendar_link_enabled": true
} }
```

### 2.2 PUT /settings
请求（全部可选，仅更新传入字段）：
```json
{ "title": "王老师的学生成长档案", "teacher_name": "王老师", "theme_id": "art",
  "stage_filter": "middle", "calendar_api_base": "http://127.0.0.1:8787",
  "calendar_semester_id": "2026-autumn-1", "calendar_link_enabled": false }
```
校验：title/teacher_name ≤ 40 字非空；theme_id ∈ 主题表；stage_filter ∈ {all,primary,middle}；calendar_api_base 须 http(s)://host[:port]；calendar_semester_id 存在性不强制（联动时兜底）。
响应：`{ "ok": true, "settings": {...完整} }`

### 2.3 POST /calendar/test
联动连通性测试。
请求：`{ "calendar_api_base": "http://127.0.0.1:8787" }`（缺省用设置值）
响应：`{ "ok": true, "reachable": true, "semesters": [{ "id", "name", "start_date", "end_date" }] }`
失败：`{ "ok": false, "reason": "无法连接教学日历（...）" }`（HTTP 200，reachable=false 语义用 ok 区分）

## 3. 班级接口

### 3.1 GET /classes
列表。查询参数：`role`(homeroom|subject，缺省全部)、`stage`(all|primary|middle，缺省 all)。
响应：
```json
{ "ok": true, "classes": [{
  "id": "pf_cls_...", "name": "初一(5)班", "grade": "初一", "stage": "middle",
  "role": "homeroom", "sort_order": 1, "student_count": 45,
  "created_at": "...", "updated_at": "..."
}], "total": 1 }
```

### 3.2 POST /classes
请求：`{ "name": "四(4)班", "grade": "四年级", "stage": "primary", "role": "subject" }`
校验：name 必填 ≤20 字且班级库内唯一（409）；grade 必填 ≤20 字；stage/role ∈ 枚举。
响应：`{ "ok": true, "class": {...完整} }`

### 3.3 PUT /classes/:cid
请求（部分更新）：`{ "name"?, "grade"?, "stage"?, "role"?, "sort_order"? }`
改名校验唯一；改 role 时：homeroom → subject 需二次确认参数 `{ "confirm_role_change": true }`（主班全功能数据保留但不可见，恢复 homeroom 后重现）。
响应：`{ "ok": true, "class": {...} }`

### 3.4 DELETE /classes/:cid
请求：`{ "confirm_name": "初一(5)班" }`（必须与班级名一致，防误删）
行为：级联删除该班学生、成绩、作业、德育、特长荣誉、素材（物理删除，先入撤销栈）。
响应：`{ "ok": true, "deleted": "pf_cls_..." }`

## 4. 学生接口

### 4.1 GET /classes/:cid/students
列表。查询参数：`stage`、`keyword`(姓名/学号模糊)、`gender`、`boarding`(0/1)、`pressure_level`、`page`、`page_size`。
响应（敏感字段**脱敏**）：
```json
{ "ok": true, "students": [{
  "id": "pf_stu_...", "class_id": "pf_cls_...", "name": "李想", "student_no": "20260101",
  "gender": "男", "birth_date": "2011-09-01", "school_id": "G20260101",
  "id_card": "420***********1234", "address": "湖北省武汉市****",
  "parent1_name": "李**", "parent1_phone": "138****5678", "parent2_name": "", "parent2_phone": "",
  "guardian_note": "", "special_note": "🔒", "allergy_note": "🔒", "manage_note": "🔒",
  "is_boarding": 1, "pressure_level": "中", "puberty_status": "", "goal_note": "",
  "subject_note": "", "active": 1, "created_at": "...", "updated_at": "..."
}], "total": 45, "page": 1, "page_size": 100 }
```
> special_note/allergy_note/manage_note/guardian_note 在列表接口仅返回 `"🔒"` 占位（脱敏）；明文见 4.4。

### 4.2 POST /classes/:cid/students
请求（主班全字段；代课班仅 name/student_no/subject_note 有效，其余忽略并返回 warning 列表）：
```json
{ "name": "李想", "student_no": "20260101", "gender": "男", "birth_date": "2011-09-01",
  "school_id": "G20260101", "id_card": "4201...", "address": "湖北省武汉市...",
  "parent1_name": "李建国", "parent1_phone": "13800005678", "parent2_name": "王芳", "parent2_phone": "13900001234",
  "guardian_note": "", "special_note": "单亲，随母", "allergy_note": "青霉素过敏", "manage_note": "座位靠前",
  "is_boarding": 1, "pressure_level": "中", "puberty_status": "变声期", "goal_note": "目标重点高中",
  "subject_note": "" }
```
校验：name 必填；student_no 班级内唯一（409）；gender ∈ {男,女}；birth_date 合法且 ≤ 今天；pressure_level ∈ 枚举。
响应：`{ "ok": true, "student": {...明文}, "warnings": [] }`

### 4.3 PUT /students/:sid
部分更新，字段同 4.2；`active` 可设 0（停用，不物理删除，列表默认过滤）。
响应：`{ "ok": true, "student": {...明文} }`

### 4.4 GET /students/:sid
单个学生详情（敏感字段**明文**，仅本人使用）。
响应：`{ "ok": true, "student": {...}, "class": { "id","name","stage","role" } }`

### 4.5 POST /classes/:cid/students/import
批量导入（CSV 文本）。
请求：`{ "rows": [{ "name","student_no","gender","birth_date","school_id","id_card","address","parent1_name","parent1_phone","parent2_name","parent2_phone","guardian_note","special_note","allergy_note","manage_note","is_boarding","pressure_level","puberty_status","goal_note","subject_note" }] }`
（首行可为表头；服务端逐行校验，行号从 2 计）
响应：`{ "ok": true, "imported": 44, "failed": 1, "errors": [{ "row": 5, "reason": "学号重复" }] }`

### 4.6 GET /classes/:cid/students/export?masked=1
导出 CSV（默认 masked=1 脱敏；masked=0 需带 `"confirm": true` 参数头 `X-Confirm-Plain: 1`）。
响应：`text/csv; charset=utf-8`，列：姓名,学号,性别,出生年月,学籍号,身份证号,家庭住址,家长1姓名,家长1电话,家长2姓名,家长2电话,监护人备注,家庭特殊情况,过敏史,管理注意事项,住校,压力等级,青春期状态,升学目标,学科备注。

### 4.7 GET /students/export/archive/:sid（导出单生档案）
学生个人完整档案导出（文本/PDF 风格 Markdown）：基础信息（脱敏开关）+ 成绩表 + 作业统计 + 德育汇总 + 荣誉 + 素材清单 + 已保存评语。
响应：`text/markdown; charset=utf-8`。

## 5. 成绩接口

### 5.1 POST /classes/:cid/exams
创建考试。
请求：`{ "name": "第一次月考", "type": "monthly", "date": "2026-10-15", "note": "" }`
校验：name 必填；type/date 合法；同班同 type 同日重名 → 409。
响应：`{ "ok": true, "exam": { "id","class_id","name","type","date","note","created_at" } }`

### 5.2 GET /classes/:cid/exams
考试列表（按日期倒序）。查询参数：`type`。
响应：`{ "ok": true, "exams": [...], "total": n }`

### 5.3 PUT /exams/:eid / DELETE /exams/:eid
更新（name/type/date/note）；删除（级联删除该考试全部成绩，入撤销栈）。
响应：`{ "ok": true, "exam": {...} }` / `{ "ok": true, "deleted": "pf_exm_..." }`

### 5.4 POST /exams/:eid/scores/batch
批量录入成绩（粘贴表格）。
请求：
```json
{ "rows": [
  { "student_id": "pf_stu_...", "subject": "语文", "score": 92, "class_rank": 3, "grade_rank": 15 },
  { "student_id": "pf_stu_...", "subject": "总分", "score": 560, "total_rank": 5 }
] }
```
- 每行校验：student_id 属于该考试班级；subject 非空；score 0~100（总分可为任意非负，subject='总分' 时不做 0-100 限制）；rank 正整数。
- 覆盖语义：同 (exam_id, student_id, subject) 已存在 → 更新（upsert）。
- 附加题型得分（道法）：行内可带 `"question_scores": { "选择": 12, "简答": 8, "材料分析": 6, "论述": 5 }`（key ∈ 题型名，value 为该题得分）。
响应：`{ "ok": true, "upserted": n, "failed": m, "errors": [{ "row": 2, "reason": "..." }] }`

### 5.5 GET /exams/:eid/scores
某考试全部成绩（按学生、科目）。
响应：`{ "ok": true, "exam": {...}, "scores": [{ "id","exam_id","student_id","student_name","subject","score","class_rank","grade_rank","question_scores": {...} }] }`

### 5.6 GET /students/:sid/scores
学生全部成绩（按时间升序）。
响应：`{ "ok": true, "scores": [{ "exam_id","exam_name","exam_type","exam_date","subject","score","class_rank","grade_rank","total","total_rank" }] }`
> `total`/`total_rank` 由服务端从该考试该生 subject='总分' 行投影注入（同一考试内）。

### 5.7 GET /students/:sid/analysis
个人学情分析（自动计算）。
响应：
```json
{ "ok": true, "analysis": {
  "trends": [{ "exam_id","exam_name","exam_date","total","total_rank","delta_total": -8, "delta_rank": 2 }],
  "status": "stable | up | down | volatile",
  "subject_trends": { "语文": [{ "exam_id","date","score","delta": 5 }] },
  "weak_points": [{ "subject": "数学", "avg_score": 61, "below_class_avg": -8.4, "last_rank": 28, "note": "连续两次低于班级均分" }],
  "question_weak": [{ "question_type": "材料分析", "avg_loss_rate": 0.45, "level": "high" }]
} }
```
规则（固定）：
- delta_total = 本次总分 − 上次总分；delta_rank 同理（名次上升为正）。
- status 判定优先级：≥3 次且标准差 > 8 → volatile；否则末两次总分差 ≥5 → up、≤-5 → down；否则 stable。
- weak_points：科目平均分低于班级均分 ≥5 分且出现 ≥2 次。
- question_weak：仅「道德与法治」科目有题型数据时计算；loss_rate = (满分−均分)/满分 > 0.3 记 high。

### 5.8 GET /classes/:cid/analysis?exam_id=xxx（班级学情）
响应：
```json
{ "ok": true, "analysis": {
  "exam": { "id","name","date" }, "prev_exam": { "id","name","date" },
  "stats": { "avg_total": 512.3, "excellent_rate": 0.18, "pass_rate": 0.92,
             "segments": { "lt60": 3, "60-69": 6, "70-79": 14, "80-89": 16, "ge90": 6 } },
  "subject_stats": { "语文": { "avg": 88.2, "excellent_rate": 0.4, "pass_rate": 1.0 } },
  "movement": { "up_count": 12, "down_count": 8, "stable_count": 25 },
  "ranking": [{ "student_id","student_name","total","total_rank" }]
} }
```
- 分数段口径（固定）：<60 / 60-69 / 70-79 / 80-89 / ≥90；优秀 ≥85；及格 ≥60。
- 优秀率/及格率/分数段按**单科成绩池**（百分制，不含总分行）口径；avg_total 为总分均值。
- movement 对比 prev_exam（该班该考试类型上一次考试；无则全 0）。

### 5.9 GET /df/compare（道法多班对比）
查询参数：`stage`(primary|middle|all)、`exam_type`(缺省取各班最近一次 monthly 及以上类型)。
响应：
```json
{ "ok": true, "compare": [{
  "class_id","class_name","role", "stage",
  "exam_id","exam_name","exam_date",
  "avg": 82.5, "excellent_rate": 0.3, "pass_rate": 0.95,
  "segments": {...}, "prev_avg": 80.1, "avg_delta": 2.4,
  "student_count": 45
}], "rule_note": "各班最近一次同类型考试对齐对比" }
```
- 参与班级 = role=subject 班级 ∪ role=homeroom 班级（主班自动纳入，字段 role 标注 homeroom）。
- subject 固定取「道德与法治」。

## 6. 作业接口

### 6.1 POST /classes/:cid/assignments
布置作业。
请求：`{ "subject": "数学", "date": "2026-10-15", "title": "练习册 P12-15", "requirement": "家长签字", "deadline": "2026-10-16" }`
响应：`{ "ok": true, "assignment": { "id","class_id","subject","date","title","requirement","deadline","status":"pending","created_at" } }`

### 6.2 GET /classes/:cid/assignments
列表。查询：`subject`、`status`、`date_from`、`date_to`。
响应：`{ "ok": true, "assignments": [...], "total": n }`

### 6.3 PUT /assignments/:aid / DELETE /assignments/:aid
更新（含 status → closed 关闭登记）；删除（级联删除记录）。
响应：`{ "ok": true, "assignment": {...} }` / `{ "ok": true, "deleted": "pf_aw_..." }`

### 6.4 POST /assignments/:aid/records/batch
批量登记作业完成状态。
请求：`{ "rows": [{ "student_id", "status": "missing", "issue_note": "未交", "rectify_note": "次日补交" }] }`

### 13.4 联动映射规则（固定契约）
| 档案字段 | 日历事件字段 | 值 |
|---|---|---|

| time | time | 透传（空则空串） |
| location | location | 透传 |
| note | notes | `【成长档案】{type_label}：{note}` |
| — | participants | `{学生姓名}（{班级名}）` |
| — | color | `#C97B84`（固定，与日历谈心色一致） |
| — | requirements | `""` |
