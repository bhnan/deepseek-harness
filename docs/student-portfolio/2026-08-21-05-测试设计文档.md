# 学生成长档案工作台 · 测试设计文档（定稿版）

> 文档编号：PF-TEST-2026-08-21 ｜ 版本：v1.0（定稿）
> 基线：接口文档 03 全部 77 个接口；数据结构文档 04 schema_version=1

## 1. 测试分层与范围

| 层 | 对象 | 工具 |
|---|---|---|
| L1 单元 | 分析引擎（进退步/波动/分层/统计）、加密模块、脱敏规则、学期推导、占位符替换、评语模板渲染、推送轮转 | Vitest 纯函数 |
| L2 接口 | 全部 REST 接口（03 文档），spawn 独立端口服务 | Vitest + fetch |
| L3 集成 | 唯一联动（沟通安排 → 教学日历）、备份/恢复、撤销/重做跨实体 | Vitest + 双服务 |
| L4 UI | 关键页面冒烟（导航、Tabs、弹窗、筛选） | 浏览器自动化（DSH iframe） |
| L5 数据一致性 | 外键/唯一约束/加密字段/幂等/枚举防漂移 | Vitest 直接查库断言 |

## 2. 测试环境

- 独立数据目录：`TC_DATA_DIR=<tmp>/pf-test-*`，测试后清理。
- 服务端口：API `8797`（测试专用 `PORT=8798` 避免冲突）；联动目标模拟教学日历（起一个 stub server 或真实教学日历服务于 8787/8799）。
- 种子工厂：`测试工厂` 提供 makeClass/makeStudent/makeExam/makeScore/makeHW… 保证用例自包含。
- 断言基线：所有期望值按 03 文档 schema 字段命名；列表接口校验 total/page 分页行为。

## 8. 回归与发布门禁

1. `vitest run` 全绿（L1+L2+L5 自动化；L3 含 stub；L4 冒烟手动/半自动）。
2. 覆盖率目标：引擎与加密模块 ≥ 90%，接口层关键路径 ≥ 80%。
3. 每轮 schema 变更必须：更新 03/04 文档 → 更新受影响用例 → 全量回归。
4. 发布前执行：备份→恢复→撤销→重做→联动全链路冒烟（对应 I-96~I-105、L-01~L-12）。
