# Agent Note：移动 Web 对话框和侧边栏使用紧凑控件

状态：已实现

[English](2026-09-05-mobile-web-composer-and-sidebar.md) | 中文

## 问题

Web 对话框新增附件操作时没有适配窄屏浏览器宽度。展开的选择器可能与对话框重叠，收起的移动端侧边栏仍占用桌面端轨道，压缩了对话区域。

## 决策

在窄屏视口中，收起的侧边栏占用零个布局列，并渲染一个适配安全区的固定重新打开按钮。桌面端继续保留紧凑轨道，因此现有指针和键盘行为不变。

对话框在附件插槽中只拥有一个附件选择器。移动端选择器使用底部面板，从用户手势直接调用原生文件输入，并在选择后重置输入，使用户可以再次选择同一个文件。文件和照片输入通过本地化标签保持可访问，并在关闭后恢复键盘焦点。

## 结果

移动端附件操作保持在视口内，不再与消息提交控件争用空间。侧边栏关闭时从移动端布局中移除，但固定的重新打开控件仍位于对话区域上方。上传失败仍由对话框负责呈现；选择器只释放忙碌状态。

## 验证

附件、对话框、布局、侧边栏和 elevation 聚焦测试共 167 项通过。UI 改动后的仓库类型检查通过。分支推送前还需通过 Web 快照回放和 GUI 门禁。
